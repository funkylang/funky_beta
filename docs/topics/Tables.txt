# Tables

  A table is an associative array that maps keys to values. It is the base
  type for all key-value stores in Funky and is derived from
  <std_types::collection>.

  Like every collection in Funky, a table is **immutable**. "Modifying" a
  table -- adding, changing, or deleting an entry -- returns a new table that
  shares structure with the original; the original table remains unchanged.

  A table is used as a function to read and write entries:

  * `table(key)` -- reads the value stored for <key> (returns
    <std::undefined> if the key is absent)
  * `!table(key) value` -- clones the table with <key> bound to <value>
  * `!table(key) undefined` -- clones the table with <key> removed

  Table variants:

  * `<std_types::table>` -- the abstract base type, derived from
    <std_types::collection>
  * `<std_types::hash_table>` -- unordered, constant-time lookup (the default)
  * `<std_types::key_order_table>` -- entries kept in key order
  * `<std_types::binary_table>` -- an ordered binary-tree table
  * `<std_types::avl_table>` -- a self-balancing binary table (an
    <std_types::binary_table>)
  * `<std_types::lb2_table>` -- a leaner balancing binary table (an
    <std_types::binary_table>)
  * `<std_types::insert_order_table>` -- entries kept in insertion order
  * `<std_types::association_list>` -- a table backed by an ordered list

  Each variant has an `empty_...` prototype (e.g. <std::empty_hash_table>)
  and a constructor that builds a table from key-value pairs:

  * Construction: <std::empty_hash_table>, <std::hash_table>
  * Reading: <std_types::hash_table/:> (the type function)
  * Inspecting: <std::keys_of>, <std::values_of>, <std::length_of>
  * Adding: <std_types::table/std::add>
  * Merging: <std_types::table/std::merge>, <std_types::table/std::difference>
  * Iterating: <std_types::hash_table/std::for_each>, <std_types::hash_table/std::map>,
    <std_types::hash_table/std::reduce>
  * Testing: <std::is_a_table>, <std::is_a_hash_table>, <std::is_a_key_order_table>
  * Converting: <std::to_hash_table>, <std_types::table/std::to_list>

  Iteration order depends on the variant. A <std_types::hash_table> visits
  entries in an unspecified order; a <std_types::key_order_table> and a
  <std_types::insert_order_table> visit them in key order and insertion order
  respectively.

  Example:

    $ages empty_hash_table
    !ages("Alice") 30
    !ages("Bob") 25
    !ages("Carol") 41

    println! ages("Alice")

    !ages("Alice") 31
    println! ages("Alice")

    !ages("Dave") 29
    println! length_of(ages)

    for_each ages
      : (name age)
        println! name ": " age
        next!
      pass

  Output:

    30
    31
    4
    Dave: 29
    Bob: 25
    Alice: 31
    Carol: 41
