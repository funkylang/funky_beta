# Collections

  There are several kinds of collections

  * arrays

  * bags

  * lists

  * sets

  * tables

  * tuples

  Sets, bags and tables come in several variants, that offer specific features.

  Collections have type functions that allow retrieving and "updating"
  individual elements in the collection.

  When a collection is "updated" a new collection is created where the
  element is changed. The original collection is not changed.

  Related topics: Arrays, Bags, Lists, Sets, Tables, Tuples

  Example:

    $items list(10 20 30)
    print! "List: " trim_left(debug::to_string(items 0 2))
    println! ""

    $prices hash_table("Apples" = 350 "Oranges" = 275)
    print! "Table: " trim_left(debug::to_string(prices 0 2))
    println! ""

    $first items(1)
    println! "First item: " first

  Output:

    List: list
      10
      20
      30

    Table: hash_table
      "Oranges" = 275
      "Apples" = 350

    First item: 10
