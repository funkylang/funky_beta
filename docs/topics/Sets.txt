# Sets

  A set is an unordered collection of unique items. Each value can appear
  only once, and sets provide efficient membership testing and fast insertion.

  Sets are immutable; operations that add or remove items return a new set.
  Several variants exist: hash_set (hash-backed), key_order_set (sorted),
  and insert_order_set (preserves insertion order).

  Related topics: Collections, Tables

  Example:

    $fruits hash_set("Apple" "Orange" "Banana")
    print! "Fruits: " trim_left(debug::to_string(fruits 0 2))
    println! ""

    $count length_of(fruits)
    println! "Count: " count

  Output:

    Fruits: hash_set
      "Orange"
      "Apple"
      "Banana"

    Count: 3
