# Bags

  Bags are "multi-sets". A bag keeps a record of how many of each element
  is stored.

  A bag can contain a negative number of elements!

  The only bag variant is <std_types::hash_bag>, derived from
  <std_types::hash_table>. It stores a count for each key:

  * <std::empty_hash_bag> -- the empty prototype
  * <std::hash_bag> -- constructor from key-value pairs
  * Calling the bag with a key retrieves the count; calling it with a key
    and a count sets the count
  * <std_types::hash_bag/std::add> -- increases or decreases counts, also
    accepts bare items (count one)
  * <std_types::hash_bag/std::merge> -- sums the counts of two bags
  * <std_types::hash_bag/std::difference> -- subtracts one bag from another
  * <std::to_hash_bag> -- converts a collection into a hash bag

  Example:

    $inventory empty_hash_bag
    !inventory("apple") 3
    !inventory("pear") 5
    !inventory("banana") 1

    $restock add(inventory "apple" = 2 "fig" = 1)
    println! "apple: @(restock("apple"))"
    println! "fig: @(restock("fig"))"
    println! "items: @(length_of(restock))"

    $sold difference(restock inventory)
    debug::dump 99 `sold

  Output:

    apple: 5
    fig: 1
    items: 4

  Error output:

    sold:
      hash_bag
        "apple" = 2
        "fig" = 1
