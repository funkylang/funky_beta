# Strings

  A string is an ordered sequence of characters. Each character is a tagged
  unsigned 32-bit integer -- typically a Unicode code point, but also usable
  for other values like 24-bit colour codes.

  Strings use one-based indexing. Negative indices count from the end.
  Accessing a single character is an O(1) operation.

  Strings, like all Funky objects, are **immutable**. Operations that
  "modify" a string return a new string that shares structure with the
  original when possible. This makes push (amortized O(1)), range (O(1)),
  and single-character replacement (amortized O(1)) efficient.
  Appending multiple strings in one call is more efficient than chaining
  single-appends.

  Key string operations:

  * Construction: <std::string>, <std::create_string>, <std::empty_string>
  * Access: <std::range> (substring), <std::push> (append character),
    <std::length_of>
  * Searching: <std::search> (find substring position)
  * Extraction: <std::before>, <std::behind>, <std::between>
    <std::until>, <std::from>
  * Truncation: <std::truncate_before>, <std::truncate_behind>
    <std::truncate_from>, <std::truncate_until> -- return the original
    string if the expression is not found
  * Prefix/suffix: <std::has_prefix>, <std::has_suffix>,
    <std::without_prefix>, <std::without_suffix>
  * Matching: <std::matches>, <std::match>, <std::match_back>,
    <std::contains>
  * Transformation: <std::to_upper_case>, <std::to_lower_case>
    <std::to_title_case>, <std::to_sentence_case>, <std::dup>
  * Conversion: <std::to_integer>, <std::to_number>, <std::to_wide>
  * I/O: <std::load> (read from file), <std::save> (write to file),
    <std::edit> (interactive terminal editing)

  Subtypes:

  * <std_types::octet_string> -- 8-bit characters, used for binary data
    or UTF-8 encoded strings. Generated automatically when all characters
    fit in 8 bits.
  * <std_types::wide_string> -- fixed-width character encoding for
    terminal rendering. Create with <std::to_wide>.

  Strings share the list API: push, pop, drop, peek, range, append,
  and length_of all work on strings just as they do on lists.

  Related topics: Collections, Lists, Characters

  Example:

    $msg "Hello, Funky!"
    print! msg
    println! ""

    $length length_of(msg)
    println! "Length: " length

    $upper to_upper_case(msg)
    println! "Upper: " upper

  Output:

    Hello, Funky!
    Length: 13
    Upper: HELLO, FUNKY!
