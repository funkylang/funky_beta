# std::from_unix_time (a function)

  constructs a date-and-time from Unix epoch seconds

  Parameter:
    seconds: an integer count of seconds since 1970-01-01 00:00:00 UTC

  Result:
    value: a date-and-time object

  Converts a count of whole seconds since 1970-01-01 00:00:00 UTC into a
  date-and-time object. The nanosecond component is set to zero.

  Topic: Date and Time

  See also: std::date_and_time, std::current_time, std::seconds_since_epoch

  Example:

    $t from_unix_time(1704067200)
    println! t

  Output:

    2024-01-01 1:00:00.000 GMT+1
