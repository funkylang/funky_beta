# std-2.0::indent_of (a polymorphic function)

  returns the indentation level of a line object

  Parameter:
    line: a <std_types-2.0::line> object

  Result:
    indent: the indentation in column positions (spaces count as 1, tabs as 8)

  Returns the number of leading whitespace columns of the line. Tabs are
  expanded to 8-column positions, so a single tab before text yields 8.

  Topic: Strings

  See also: std-2.0::text_of, std-2.0::split_into_indented_lines

  Example:

    <using std-2.0>

    $text "  hello@nl;	world@nl;"
    $lines split_into_indented_lines(text)
    $line1 lines(1)
    $indent indent_of(line1)
    dump! `indent

  Output:

    indent: 2
