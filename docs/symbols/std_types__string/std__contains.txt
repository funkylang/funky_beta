# std_types::string/std::contains (a method)

  checks whether a string contains the specified expression

  Parameters:
    self: the string to check
    expr: the expression to look for

  Result:
    true if the expression occurs at least once in the string, false otherwise

  A string contains an expression when the expression can be found at any
  position within the string, including the beginning and the end. Only the
  occurrence is tested; unlike the truncate and before/behind functions no
  part of the string is removed.

  Topic: Strings

  See also: std::matches, std::has_prefix, std::has_suffix

  Example:

    $path "/home/hermes/projects/funky_beta"
    if path .contains. "funky"
      :
        println! "path contains funky"
      :
        println! "path does not contain funky"
    if path .contains. "python"
      :
        println! "path contains python"
      :
        println! "path does not contain python"

  Output:

    path contains funky
    path does not contain python
