# std::string (a function)

  concatenates all arguments into a single string

  Parameter:
    args*: zero or more values to concatenate (each converted to string)

  Result:
    string: the concatenation of all arguments

  Every argument is converted to its string representation via to_string
  and the results are joined together. This is equivalent to passing a list
  of items to create_string.

  Topic: Strings

  See also: create_string, to_string, append

  Example:

    $result string("2 + 2 = " 4)
    println! result  # "2 + 2 = 4"

    $formatted string(7 " x " 7 " = " 7*7 '@nl;')
    print! formatted  # "7 x 7 = 49" followed by newline
