# std_types::array/std::serialization_tag_of (an attribute)

  returns the serialization tag identifying an array type

  Parameter:
    self: the array

  Result:
    tag: a string containing the serialization tag

  Serialization tags identify the type during deserialization so the
  runtime knows which constructor to invoke. For std_types::array
  the tag is "array".

  Topic: Data Exchange

  See also: std::serialize, std::deserialize, std_types::array

  Example:

    $a array(3)
    $tag serialization_tag_of(a)
    println! "serialization tag: " tag

  Output:

    serialization tag: array
