# std_types::array/std::length_of (a method)

  returns the length of a given dimension, or total items for 1D arrays

  Parameter:
    array: the array to query
    dimension?: the dimension (1-based), required for multi-dimensional arrays

  Result:
    length: element count along the dimension, or total items for 1D arrays

  On a one-dimensional array it returns the total element count with no extra
  argument. On multidimensional arrays the second argument selects which
  dimension to query and its size is returned.

  Topic: Arrays

  See also: std::length_of

  Example:

    $print_array: (data)
      $row_count length_of(data 1)
      $column_count length_of(data 2)
      $separator_line append("+" dup("---------+" column_count))
      println! separator_line
      from_to 1 row_count
        : (row_no)
          print! "|"
          from_to 1 column_count
            : (column_no)
              $value data(row_no column_no)
              print! pad_left(value 9) "|"
              next!
          println!
          println! separator_line
          next!
        pass
