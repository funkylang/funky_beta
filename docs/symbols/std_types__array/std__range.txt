# std_types::array/std::range (a method)

  creates a subrange of an array by specifying slices per dimension

  Parameters:
    array: the source array
    ranges: one value range per dimension (or bare index for a single element)

  Result:
    result: a new array containing the specified elements

  Trailing dimensions may be omitted — all elements along those
  dimensions are included. For a single-element range, use the bare
  index (e.g. 3) instead of 3..3.

  Topic: Arrays

  See also: std::range, std_types::array

  Example:

    $nums initialized_array(5 0)
    from_to !nums 1 5
      : (i)
        !nums(i) i*10
        next
      -> nums
    $slice range(nums 2..4)
    println! "original: " length_of(nums) " elements"
    println! "slice (2..4): " length_of(slice) " elements"
    from_to 1 3
      : (i)
        println! "  position " i ": " slice(i)
        next!
      pass

  Output:

    original: 5 elements
    slice (2..4): 3 elements
      position 1: 20
      position 2: 30
      position 3: 40
