# std_types::hash_bag/std::add (a method)

  adds items with or without explicit counts to a bag

  Parameters:
    self: the bag to add the items to
    pairs*: one or more items or key-value pairs

  Result:
    the updated bag

  Adds the given items to the bag. An item given as a key-value pair
  increases the count by the given value; an item given on its own
  increases the count by one. If the item is not present yet, it is
  added. A negative count decreases the count of the item. When a
  count reaches zero, the item is removed from the bag. A cloned bag
  with the changes is returned; the original bag remains unchanged.

  Topic: Bags

  See also: std_types::hash_bag/std::merge,
            std_types::hash_bag/std::difference

  Example:

    $basket empty_hash_bag
    add &basket
      "apple" = 2
      "pear"
      "banana"
    debug::dump 99 `basket
    add &basket "apple" = -2
    debug::dump 99 `basket

        "apple" = 2
        "banana" = 1

      hash_bag
        "pear" = 1
        "banana" = 1
