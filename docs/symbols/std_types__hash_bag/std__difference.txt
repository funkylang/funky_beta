# std_types::hash_bag/std::difference (a method)

  computes the difference of two hash bags

  Parameters:
    self: the base bag
    other: the bag to subtract

  Result:
    the difference of the two bags

  The difference contains the base bag with the counts of the other
  bag subtracted from it. For a key present in both bags, the other
  bag's count is subtracted from the base count. Keys only present in
  the other bag appear with a negative count. If a count becomes zero,
  the key is not present in the result. A cloned bag is returned; both
  original bags remain unchanged.

  Topic: Bags

  See also: std_types::hash_bag/std::merge,
            std_types::hash_bag/std::add

  Example:

    $shelves empty_hash_bag
    !shelves("apple") 3
    !shelves("pear") 5
    !shelves("banana") 2
    $orders empty_hash_bag
    !orders("apple") 1
    !orders("pear") 5
    !orders("mango") 4
    $left difference(shelves orders)
    debug::dump 99 `left

  Error output:

    left:
      hash_bag
        "mango" = -4
        "apple" = 2
        "banana" = 2
