# std_types::hash_bag/: (a type function)

  retrieve, set, or remove a key's count

  Parameters:
    key: the lookup key
    value?: new count for the key (or zero/undefined to remove)

  Result:
    the count on retrieval, or the modified bag on set/remove

  Calling a <std_types::hash_bag> behaves differently depending on
  the number of arguments.

  **One argument:** the key's count is retrieved. The call returns
  the count, or <undefined> if the key is not present.

  **Two arguments:** the bag is modified. The second argument is the
  new count for the key, replacing any previous count. If the key is
  not present yet, it is added. A cloned bag with the change is
  returned; the original bag remains unchanged.

  Setting the count to zero removes the key, just like passing
  <undefined>. A bag therefore never contains a zero-count key.
  Removing a non-existent key returns the original bag unchanged.

  Topics: Bags, Collections

  See also: std::empty_hash_bag, std_types::hash_table,
            std_types::hash_bag/std::add

  Example:

    $shelves empty_hash_bag
    !shelves("apple") 3
    !shelves("pear") 5
    !shelves("banana") 2
    $pear shelves("pear")
    println! "pear: @(pear)"
    $shrunken shelves("apple" 0)
    println! "after zero, items: @(length_of(shrunken))"
    $pruned shelves("pear" undefined)
    println! "after undefined, items: @(length_of(pruned))"
    debug::dump 99 `shrunken `pruned

  Output:

    pear: 5
    after zero, items: 2
    after undefined, items: 2

  Error output:

    shrunken:
      hash_bag
        "pear" = 5
        "banana" = 2
    pruned:
      hash_bag
        "apple" = 3
        "banana" = 2
