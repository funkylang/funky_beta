# std_types::key_order_set (a type derived from std_types::object)

  a set whose items are stored in key order

  All items stored in the set must support the following methods:

  * <equal>

  * <less>

  Items are maintained in sorted key order, so iteration always
  yields the keys from smallest to largest.

  Topics: Sets, Collections

  See also: std_types::set, std_types::hash_set,
            std_types::insert_order_set, std_types::key_order_table

  Example:

    $days key_order_set("wednesday" "monday" "friday")
    dump! `days

  Output:

    days: key_order_set <3>
      "friday"
      "monday"
      "wednesday"
