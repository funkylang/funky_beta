# std::is_dark (a function)

  tests whether a colour character is dark

  Parameter:
    chr: the colour character to test

  Result:
    result: std::true if the colour is dark, std::false otherwise

  This function returns <std::true> if its brightness is less than 50%.
  Medium grey (128 per channel) is the dividing line.

  Topic: Terminal, Colours

  See also: std::red_component_of, std::green_component_of,
    std::blue_component_of

  Example:

    $silver '@0xc0c0c0;'
    dump! `(is_dark(silver))
    dump! `(is_dark('@0x000000;'))

  Output:

    (is_dark(silver)): <false>
    (is_dark('@0x000000;')): <true>
