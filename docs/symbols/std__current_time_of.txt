# std::current_time_of (a polymorphic function)

  gets the cached current time from an object

  Parameters:
    self: the object to query

  Result:
    date_and_time: the cached current time

  Returns the current time stored in the given object's
  <std::current_time_of> attribute.

  Used internally by the input-output event system to track the time
  at which events occur. The <std_types::io> object stores the time
  when its I/O cycle started, and <std_types::window_manager> stores
  the time of its last update.

  For the current system clock time, use <std::current_time> instead.

  Topic: Input-Output Events

  See also: std::current_time

  Example:

    initialize! $my_io std_types::io
    $time current_time_of(my_io)
    if time.is_defined
      : println! time
      : println! "time is undefined"
