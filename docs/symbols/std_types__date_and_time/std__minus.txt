# std_types::date_and_time/std::minus (a method)

  subtracts seconds or computes the difference between two date-and-time objects

  Parameters:
    left: a date-and-time object
    right: a number or a date-and-time object

  Result:
    result: a date-and-time object or a real number

  When right is a number, shifts backward by that many seconds. When right
  is a date-and-time, returns the difference in seconds as a real number.

  Topic: Date and Time

  See also: std_types::date_and_time/std::plus

  Example:
    $t date_and_time(2024 1 2 0 0 0)
    println! t-86400
