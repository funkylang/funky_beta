# std_types::binary_table/: (a type function)

  retrieve, insert, or delete a key-value pair from a binary table

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    result: the stored value (retrieve) or modified table (insert/delete)

  Calling a <std_types::binary_table> with a single key retrieves the
  associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a clone of the table. Keys must support comparison via
  <less> and <equal> operators. Internally, the table uses a binary
  tree where left children are at even indices and right children at
  odd indices, with in-order traversal preserving key sort order.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a clone with length decreased by one. Attempting
  to delete a non-existent key returns an unchanged clone.

  Topic: Tables

  See also: std::empty_binary_table, std_types::binary_table

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/binary_table>

    $ages empty_binary_table
    !ages("Eva") 27
    !ages("Victor") 23
    !ages("Robert") 25
    println! ages("Eva")
    !ages("Eva") 28
    println! ages("Eva")

  Output:

    27
    28
