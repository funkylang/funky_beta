# std_types::binary_table/: (a type function)

  retrieve, insert, or delete a key-value pair from a binary table

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    the stored value on retrieval, or the modified table on insert/delete

  This is an abstract base type — concrete subtypes (<std_types::avl_table>,
  <std_types::lb2_table>) provide the full implementation. The
  <std_types::binary_table> type itself contains only partial
  implementations.

  Calling a <std_types::binary_table> with a single key retrieves the
  associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a cloned table with the new entry; the original table remains
  unchanged. Keys must support comparison via <less> and <equal>
  operators. Entries are maintained in sorted key order.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a cloned table with the entry removed; the original
  table remains unchanged. Attempting to delete a non-existent key
  returns the original table unchanged.

  Topic: Tables

  See also: std::empty_binary_table, std_types::avl_table, std_types::lb2_table

  Topic: Arrays

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/binary_table>

    $ages empty_binary_table
    !ages("Eva") 27
    !ages("Victor") 23
    !ages("Robert") 25
    println! ages("Eva")
    !ages("Eva") 28
    println! ages("Eva")

  Output:

    27
    28
