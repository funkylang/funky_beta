# std_types::binary_table/std::validate (a method)

  validates the structure of a binary table

  Parameter:
    self: a binary table

  Result:
    none

  Checks whether the binary table is internally consistent. Every key
  must be stored in its correct position relative to its neighbours,
  and the stored length must match the actual number of entries. A
  valid table produces no output and execution continues normally. If
  the table is invalid, a message describing the problem is written to
  standard error and the program is aborted.

  Topic: Tables

  See also: std_types::binary_table/std::is_a_binary_table

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/binary_table>
    <require basic/types/collections/tables/avl_table>

    $ages std::empty_avl_table
    add &ages "alice" = 30 "bob" = 25 "carol" = 41
    validate ages
    println! "table is valid, size: @(length_of(ages))"

  Output:

    table is valid, size: 3
