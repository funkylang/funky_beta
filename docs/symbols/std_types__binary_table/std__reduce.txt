# std_types::binary_table/std::reduce (a method)

  computes a kind of sum from the values stored in the table

  Parameters:
    self: the table to build the "sum" from
    function: the function to apply to pairs of values
    unit: the value to return for empty tables

  Result:
    sum: the "sum" of the values stored in the table

  There is no guarantee in which order the values will be reduced (folded).

  So the reduction function must obey to the law of associativity!

  Topic: Tables

  See also: std_types::binary_table/std::map,
            std_types::binary_table/std::map_reduce

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/binary_table>

    $prices key_order_table("apple" = 80 "banana" = 50 "cherry" = 120)
    debug::dump 99 `prices
    $total reduce(prices plus 0)
    println! "Total: @(total)"

  Output:

    Total: 250

  Error output:

    prices:
      key_order_table
        "apple" = 80
        "banana" = 50
        "cherry" = 120
