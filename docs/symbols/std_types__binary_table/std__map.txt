# std_types::binary_table/std::map (a method)

  applies a function to all values of the binary table

  Parameters:
    self: the binary table whose values will be mapped
    function: the function to apply to each element

  Result:
    a binary table containing the mapped values

  Returns a cloned binary table with each value transformed by the function;
  the original table remains unchanged. The function is dispatched based
  on its parameter count.

  **Two parameters:** the function receives the key and the value for each
  item, allowing the transformation to depend on the key.

  **One parameter:** the function receives only the value; the key is not
  passed.

  The function applications may be executed in parallel. The callback is
  invoked without I/O-access rights.

  *Currently not working for <std_types::avl_table> due to a bug in its
  implementation.*

  Topic: Tables

  See also: std_types::binary_table/std::reduce,
            std_types::binary_table/std::map_reduce

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/binary_table>

    $prices key_order_table("apple" = 80 "banana" = 50 "cherry" = 120)
    debug::dump 99 `prices
    map $as_strings
      prices
      to_string
    debug::dump 99 `as_strings

  Error output:

        "banana" = 50
        "cherry" = 120
    as_strings:
