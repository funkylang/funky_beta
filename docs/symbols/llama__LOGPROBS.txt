# llama::LOGPROBS (a unique item)

  the logprobs option for llama-server completion requests

Use as a key in the options of <llama::complete> to request logit probabilities.
Pass an integer N greater than 0 for the N most likely token candidates per
position. When set, the function returns a second result: a list of
key-value pairs mapping each token to its logprob. When omitted or
zero, no logit data is returned.

  Topic: AI

  See also: llama::complete, llama::MAX_TOKENS

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $text $probs "The answer is"
      LOGPROBS = 2
      MAX_TOKENS = 3
      TEMPERATURE = 0

    println! text

    debug::dump 99 `probs
