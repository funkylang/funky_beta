# llama::REPETITION_PENALTY (a unique item)

  the repetition penalty option for llama-server completion requests

Use as a key in the options of <llama::complete> to penalize repeated sequences
of tokens. A value above 1.0 makes recently used tokens less likely, reducing
repetitive output. The server default is 1.0 (no penalty). When omitted, the
server uses its default setting.

  Topic: AI

  See also: llama::complete, llama::TEMPERATURE

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "The quick brown fox"
      REPETITION_PENALTY = 1.2
      MAX_TOKENS = 5

    println! result

  Output:

    jumps over the lazy dog
