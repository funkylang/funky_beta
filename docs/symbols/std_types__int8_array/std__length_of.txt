# std_types::int8_array/std::length_of (a method)

  returns the length of a dimension in a signed 8-bit array

  Parameters:
    array: a signed 8-bit array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::int8_array/std::dimension_count_of

  Example:

    $readings int8_array(5)
    !readings(1) 42
    !readings(2) 37
    !readings(3) 51
    !readings(4) 44
    !readings(5) 39

    $len length_of(readings)
    println! "readings count: " len

    $matrix int8_array(2 3)
    println! "rows: " length_of(matrix 1)
    println! "columns: " length_of(matrix 2)

  Output:

    readings count: 5
    rows: 2
    columns: 3
