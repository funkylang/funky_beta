# std_types::int8_array/: (a type function)

  gets or sets an element in an int8 array

Calling a <std_types::int8_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are 8-bit signed integers between -128 and 127.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged. Values outside
  the range wrap using modulo arithmetic.

  Topic: Arrays

  See also: std_types::int8_array, std::empty_int8_array

  Example:

    $temperature int8_array(4)
    !temperature(1) 21
    !temperature(2) -5
    println! "First reading: " temperature(1)

  Output:

    First reading: 21
