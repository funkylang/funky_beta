# std_types::int8_array/std::create_empty_array (a method)

  creates an empty array with the same dimensions as template, all values zero

  Parameters:
    template: a signed 8-bit array used as the dimensional template

  Results:
    a new signed 8-bit array with the same shape, all elements set to zero

  Returns a fresh array matching the template dimensions, but with every element
initialized to zero. The original array remains unchanged.

  Topic: Arrays

  See also: std::int8_array, std::initialized_int8_array

  Example:

    $temps int8_array(3)
    !temps(1) 22
    !temps(2) -3
    !temps(3) 15

    $reset temps.create_empty_array
    print! "temps: " trim_left(debug::to_string(temps 0 3))
    print! "reset: " trim_left(debug::to_string(reset 0 3))

    reset: <int8_array(1..3)>
