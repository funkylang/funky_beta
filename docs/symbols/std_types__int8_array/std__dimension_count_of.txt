# std_types::int8_array/std::dimension_count_of (a method)

  returns the number of dimensions of a signed 8-bit array

  Parameter:
    array: a signed 8-bit array

  Result:
    the number of dimensions as an integer

  A one-dimensional array returns 1, a two-dimensional array returns 2, etc.

  Topic: Arrays

  See also: std::dimension_count_of, std_types::int8_array/std::length_of

    !temperatures(2) 19
    !temperatures(3) 24
    !temperatures(4) 21
