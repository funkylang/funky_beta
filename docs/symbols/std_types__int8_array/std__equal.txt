# std_types::int8_array/std::equal (a method)

  compares two signed 8-bit arrays element by element

  Parameters:
    left: a signed 8-bit array
    right: a signed 8-bit array

  Result:
    true if both arrays have the same shape and identical elements,
    false otherwise

  Two arrays are equal when they have matching dimensions and every
corresponding element holds the same value. Arrays with different
shapes always compare as unequal.

  Topic: Arrays

  See also: std::equal, std_types::int8_array/std::less

  Example:

    $voltages_a int8_array(3)
    !voltages_a(1) 12
    !voltages_a(2) -5
    !voltages_a(3) 7

    $voltages_b int8_array(3)
    !voltages_b(1) 12
    !voltages_b(2) -5
    !voltages_b(3) 7

    $voltages_c int8_array(3)
    !voltages_c(1) 12
    !voltages_c(2) 0
    !voltages_c(3) 7

    if
      equal(voltages_a voltages_b)
      : println! "A and B are identical"
      : println! "A and B differ"

    if
      equal(voltages_a voltages_c)
