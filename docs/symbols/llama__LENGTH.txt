# llama::LENGTH (a unique item)

  the length limit finish reason for llama-server completions

  Delivered as the finish_reason_of attribute of a
  <llama_types::metadata> object
  when generation stopped because it reached the maximum token count (MAX_TOKENS
  option). This is the standard way to detect when the model was cut off by a
  length constraint rather than finishing naturally.

  Topic: AI

  See also: llama::finish_reason_of, llama_types::metadata

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ List colors in your solar system."
      METADATA
      MAX_TOKENS = 10
      TEMPERATURE = 0

    if
      llama::finish_reason_of(meta) == LENGTH
      :
        println! "Stopped at length limit"
      :
        println! "Completed naturally"

  Output:

    Stopped at length limit
