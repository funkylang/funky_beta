# std_types-2.0::group (an object)

  a group of indented lines under a header line

  The group object wraps a <std_types-2.0::line> as a header and collects
  a list of child lines or nested groups via its <std::subgroups_of>
  attribute. Created by <std-2.0::split_into_groups>.

  The header is the first line in the group (accessed as position 1).

  Topic: Strings

  See also: std_types-2.0::line, std-2.0::split_into_groups, std::subgroups_of

  Example:

    <using std-2.0>

    $text "
      a
        1

        2
      b
        3
        4
    $lines split_into_indented_lines(text)
    $groups split_into_groups(lines)
    debug::dump 99 `groups
