  the serialization identifier for unsigned 8-bit arrays

  Parameters:

  Returns the string "uint8_array", which identifies this type during
serialization and deserialization. The tag is used internally by the
serialization framework to reconstruct the correct array type when
reading data back.

  Topic: Arrays
