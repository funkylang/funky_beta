# std_types::uint8_array/std::length_of (a method)

  returns the length of a dimension in an unsigned 8-bit array

  Parameters:
    array: an unsigned 8-bit array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::uint8_array/std::dimension_count_of

  Example:

    $pixels uint8_array(5)
    !pixels(1) 255
    !pixels(2) 128
    !pixels(3) 64
    !pixels(4) 0
    !pixels(5) 32

    $len length_of(pixels)
    println! "pixel count: " len

    $image uint8_array(2 3)
    println! "rows: " length_of(image 1)
    println! "columns: " length_of(image 2)

  Output:

    pixel count: 5
    rows: 2
    columns: 3
