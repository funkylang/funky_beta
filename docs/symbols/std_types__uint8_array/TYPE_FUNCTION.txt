# std_types::uint8_array/: (a type function)

  gets or sets an element in a uint8 array

Calling a <std_types::uint8_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are unsigned 8-bit integers between 0 and 255.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged. Values outside
  the range wrap using modulo arithmetic.

  Topic: Arrays

  See also: std_types::uint8_array, std::empty_uint8_array

  Example:

    $colors uint8_array(4)
    !colors(1) 255
    !colors(2) 128
    println! "First color value: " colors(1)

  Output:

    First color value: 255
