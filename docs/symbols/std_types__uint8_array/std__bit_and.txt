# std_types::uint8_array/std::bit_and (a method)

  performs an element-wise bitwise AND on two unsigned 8-bit arrays

  Parameters:
    left: an unsigned 8-bit array
    right: an unsigned 8-bit array of the same shape

  Result:
    a new array with each element being the bitwise AND of the corresponding
    elements in the two input arrays

  Both operands must have identical dimensions. The result is a new array; the
originals remain unchanged. If both operands are the same object, returns
that object unchanged.

  Topic: Arrays

  See also: std::bit_and, std_types::uint8_array/std::bit_or,
            std_types::uint8_array/std::bit_xor

  Example:

    $print_array: (data)
      $row_count length_of(data 1)
      $column_count length_of(data 2)
      $separator_line append("+" dup("--------+" column_count))
      println! separator_line
      from_to 1 row_count
        : (row_no)
          print! "|"
          from_to 1 column_count
            : (col_no)
              $val data(row_no col_no)
              print! " " hex(val 2) "     |"
              next!
          println!
          println! separator_line
          next!
        pass

    $mask_a uint8_array(2 3)
    !mask_a(1 1) 5
    !mask_a(1 2) 10
    !mask_a(1 3) 1
    !mask_a(2 1) 0
    !mask_a(2 2) 8
    !mask_a(2 3) 7

    !mask_b(1 3) 0
    !mask_b(2 1) 4
    !mask_b(2 2) 2
    !mask_b(2 3) 7

    println! "A:"
    print_array! mask_a
    println! ""

    println! ""
    $result mask_a .bit_and. mask_b
    println! "A & B:"
