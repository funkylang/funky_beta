# std_types::uint8_array/std::range (a method)

  creates a new unsigned 8-bit array with the elements in the given range

  Parameters:
    array: an unsigned 8-bit array
    ranges?: one or more value ranges, one per dimension

  Result:
    a new unsigned 8-bit array containing the selected elements

  The range argument is a value_range (start..end, inclusive). Supply one
range per dimension for multi-dimensional arrays. Returns a cloned array;
the original remains unchanged.

  Topic: Arrays

  See also: std::range, std_types::uint8_array/std::length_of

  Example:

    $print_array: (data)
      $row_count length_of(data 1)
      $column_count length_of(data 2)
      $separator_line append("+" dup("---------+" column_count))
      println! separator_line
      from_to 1 row_count
        : (row_no)
          print! "|"
          from_to 1 column_count
            : (col_no)
              $val data(row_no col_no)
              print! pad_left(val 9) "|"
              next!
          println!
          println! separator_line
          next!
        pass
