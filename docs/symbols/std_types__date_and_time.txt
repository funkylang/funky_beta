# std_types::date_and_time (a type derived from std_types::object)

  a specific point in time with nanosecond precision

  Supports addition and subtraction of real-valued time deltas in seconds,
  comparison with other date-and-time objects, and formatted string output
  in YYYY-MM-DD HH:MM:SS.mmm GMT+N/-N format. Calling a date-and-time
  object as a function raises a runtime error -- use the accessor functions
  instead.

  Topic: Date and Time

  See also: std::date_and_time, std::from_unix_time, std::current_time

  Example:

    $t date_and_time(2024 1 1 12 0 0)
    println! t
    println! year_of(t)
    println! month_of(t)
    println! day_of(t)
    println! seconds_since_epoch(t)

  Output:

    2024-01-01 13:00:00.000 GMT+1
    2024
    1
    1
    1704110400
