# llama::request_id_of (a polymorphic function)

  the unique identifier the server assigned to a completion

  Parameters:
    meta: a llama_types::metadata object from llama::complete

  Result:
    id: the request ID string, or undefined if not yet reported

  A unique identifier for this specific completion, generated by the
  llama-server. Useful for logging, debugging, or correlating requests across
  client and server. Each call to llama::complete produces a distinct ID.

  Topic: AI

  See also: llama_types::metadata

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Hello"
      METADATA
      MAX_TOKENS = 5
      TEMPERATURE = 0

    println! "Request ID: " debug::to_string(request_id_of(meta) 0 1)
