# std_types::int16_array/std::length_of (a method)

  returns the length of a dimension in a signed 16-bit array

  Parameters:
    array: a signed 16-bit array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::int16_array/std::dimension_count_of

  Example:

    $altitudes int16_array(4)
    !altitudes(1) 520
    !altitudes(2) -30
    !altitudes(3) 180
    !altitudes(4) 0

    $len length_of(altitudes)
    println! "altitude count: " len

    $elevation_map int16_array(2 3)
    println! "rows: " length_of(elevation_map 1)
    println! "columns: " length_of(elevation_map 2)

  Output:

    altitude count: 4
    rows: 2
    columns: 3
