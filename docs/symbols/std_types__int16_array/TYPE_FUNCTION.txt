# std_types::int16_array/: (a type function)

  gets or sets an element in an int16 array

Calling a <std_types::int16_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are 16-bit signed integers between -32768 and 32767.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged. Values outside
  the range wrap using modulo arithmetic.

  Topic: Arrays

  See also: std_types::int16_array, std::empty_int16_array

  Example:

    $pixel_values int16_array(4)
    !pixel_values(1) 32000
    !pixel_values(2) -1000
    println! "First pixel: " pixel_values(1)

  Output:

    First pixel: 32000
