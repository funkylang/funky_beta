# std_types::int16_array/std::dimension_count_of (a method)

  returns the number of dimensions of a signed 16-bit array

  Parameter:
    array: a signed 16-bit array

  Result:
    the number of dimensions as an integer

  A one-dimensional array returns 1, a two-dimensional array returns 2, and so
  on.

  Topic: Arrays

  See also: std::dimension_count_of, std_types::int16_array/std::length_of

  Example:

    $pressures int16_array(3)
    !pressures(1) 1013
    !pressures(2) 998
    !pressures(3) 1025

    println! "dimensions: " dimension_count_of(pressures)

    $grid int16_array(4 4)
    println! "grid dimensions: " dimension_count_of(grid)

  Output:

    dimensions: 1
    grid dimensions: 2
