# std_types::int16_array/std::equal (a method)

  compares two signed 16-bit arrays element by element

  Parameters:
    left: a signed 16-bit array
    right: a signed 16-bit array

  Result:
    true if both arrays have the same shape and identical elements,
    false otherwise

  Two arrays are equal when they have matching dimensions and every
corresponding element holds the same value. Arrays with different
shapes always compare as unequal.

  Topic: Arrays

  See also: std::equal, std_types::int16_array/std::less

  Example:

    $altitudes int16_array(3)
    !altitudes(1) 520
    !altitudes(2) -30
    !altitudes(3) 180

    $altitudes_copy int16_array(3)
    !altitudes_copy(1) 520
    !altitudes_copy(2) -30
    !altitudes_copy(3) 180

    $altitudes_other int16_array(3)
    !altitudes_other(1) 520
    !altitudes_other(2) 0
    !altitudes_other(3) 180

    if
      equal(altitudes altitudes_copy)
      : println! "copies match"
      : println! "copies differ"

    if
      equal(altitudes altitudes_other)
      : println! "originals match"
      : println! "originals differ"

  Output:

    copies match
    originals differ
