# llama::CACHE_PROMPT (a unique item)

  the cache prompt option for llama-server completion requests

Use in the options of <llama::complete> to enable KV cache reuse. When present,
the server reuses cached key-value states from previous completions, speeding up
repeated prefixes. Since the option defaults to true, you can specify it alone
without a key-value pair. To disable caching, pass CACHE_PROMPT = false. When
omitted entirely, the server uses its default setting.

  Topic: AI

  See also: llama::complete, llama::SEED

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "Hello, how are you"
      CACHE_PROMPT
      MAX_TOKENS = 5

    println! result
