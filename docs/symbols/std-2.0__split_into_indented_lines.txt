# std-2.0::split_into_indented_lines (a function)

  splits text into line objects with indentation tracking

  Parameters:
    text: the string to process
    keep_lineends?: keep newline characters in the line text (default false)
    proto_line?: prototype type for lines (default <std_types-2.0::line>)

  Result:
    lines: list of <std_types-2.0::line> objects

  Splits text into lines, one per newline character. Each line object
  records its leading indentation (spaces count as 1, tabs as 8) and
  its text content. The newline character is not part of the line's
  text unless *keep_lineends* is true.

  Topic: Strings

  See also: std-2.0::indent_of, std-2.0::text_of, std-2.0::split_into_groups

  Example:

    <using std-2.0>

    $text "
      a
        1

        2
      b
        3
        4
    $lines split_into_indented_lines(text)
    debug::dump 99 `lines
