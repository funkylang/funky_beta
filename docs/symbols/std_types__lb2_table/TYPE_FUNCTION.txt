# std_types::lb2_table/: (a type function)

  retrieve, insert, or delete a key-value pair from a left-biased 2-3 tree

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    result: the stored value (retrieve) or modified table (insert/delete)

  Calling a <std_types::lb2_table> with a single key retrieves the
  associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a clone of the table. Keys must support comparison via
  <less> and <equal> operators. Internally, the table uses a left-biased
  2-3 tree with automatic rebalancing on insertion and deletion. Each
  node stores its length to maintain balance properties.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a clone with length decreased by one. Attempting
  to delete a non-existent key returns an unchanged clone.

  Topic: Tables

  See also: std::empty_lb2_table, std_types::lb2_table

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/binary_table>
    <require basic/types/collections/tables/lb2_table>

    $data empty_lb2_table
    !data("alpha") 1
    !data("beta") 2
    !data("gamma") 3
    println! data("beta")
    !data("beta") 20
    println! data("beta")

  Output:

    2
    20
