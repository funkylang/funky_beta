# std_types::lb2_table/: (a type function)

  retrieve, insert, or delete a key-value pair from a left-biased 2-3 tree

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    the stored value on retrieval, or the modified table on insert/delete

  Calling a <std_types::lb2_table> with a single key retrieves the
  associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a cloned table with the change; the original table remains
  unchanged. Keys must support comparison via <less> and <equal>
  operators. The tree rebalances automatically so that no subtree is
  more than twice as large as its sibling.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a cloned table with the entry removed; the original
  table remains unchanged. Attempting to delete a non-existent key
  returns the original table unchanged.

  Topic: Tables

  See also: std::empty_lb2_table, std_types::binary_table, std_types::avl_table

  Topic: Arrays

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/binary_table>
    <require basic/types/collections/tables/lb2_table>

    $data empty_lb2_table
    !data("alpha") 1
    !data("beta") 2
    !data("gamma") 3
    println! data("beta")
    !data("beta") 20
    println! data("beta")

  Output:

    2
    20
