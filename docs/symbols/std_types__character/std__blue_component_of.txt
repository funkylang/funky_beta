# std_types::character/std::blue_component_of (a method)

  returns the blue component of a character

  Parameters:
    chr: a rgb-character

  Result:
    the blue component as a value between 0 and 255

  A colour is represented as a 24-bit value (256 shades of red, green and blue)
  and stored as a character. The bits 0..7 hold the blue component.

  Topic: Colours
