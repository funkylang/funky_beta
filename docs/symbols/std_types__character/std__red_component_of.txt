# std_types::character/std::red_component_of (a method)

  returns the red component of a character

  Parameters:
    chr: a rgb-character

  Result:
    the red component as a value between 0 and 255

  A colour is represented as a 24-bit value (256 shades of red, green and blue)
  and stored as a character. The bits 16..23 hold the red component.

  Topic: Colours

  See also: std::rgb_character, std::green_component_of, std::blue_component_of

  Example:
