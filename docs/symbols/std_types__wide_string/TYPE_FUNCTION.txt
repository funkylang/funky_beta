# std_types::wide_string/: (a type function)

  get or set a wide string character by index

  Parameter:
    self: the wide string

  Results:
    character: the character at the given index (one-based)

  Called with one argument returns the character at that position. Called
  with two arguments returns a new wide string with the character at the
  first argument replaced by the second. Wide strings hold 32-bit Unicode
  characters.

  Topic: Strings

  See also: std_types::wide_string, std::get, std::put

  Example:

    $s "你好"
    dump! `s(1) `s(2)

  Output:

    s(1): '@20320;'
    s(2): '@22909;'
