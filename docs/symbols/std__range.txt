# std::range (a polymorphic function)

  returns a subrange of a collection

  Parameters:
    collection: the collection
    start: the first index to include (one-based)
    end: the last index to include (one-based)

  Result:
    range: a new collection with the items from start to end

  Both start and end are inclusive. Negative indices count from the end
  (-1 = last item, -2 = second-to-last, etc.). An empty range is valid
  when *start* equals *end* + 1.

  Topic: Collections

  See also: std::push, std::pop, std::peek, std::drop, std::append

  Example:

    $items list(10 20 30 40 50)
    $sub range(items 2 4)
    debug::dump 99 `sub

  Output:

    sub:
      list
        20
        30
        40
