# llama::STOP (a unique item)

  the stop string option for llama-server completion requests

Use as a key in the options of <llama::complete> to provide a string that halts
generation when encountered. The model stops producing tokens once the stop
string appears in the output. When omitted, generation runs until the server's
internal end-of-sequence condition is met.

  Topic: AI

  See also: llama::complete, llama::MAX_TOKENS

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "List colors: red"
      STOP = "."
      MAX_TOKENS = 10

    println! result
