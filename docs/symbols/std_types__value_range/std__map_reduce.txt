# std_types::value_range/std::map_reduce (a method)

  combines map and reduce into a single pass over a value range

  Parameters:
    self: the value range to work on
    map_function: the function to apply to each value of the range
    reduce_function?: a two-argument combine function (defaults to <append>)

  Results:
    result: the reduced result after mapping

  The *map_function* is called once for every integer in the range, from
the lower bound to the upper bound, inclusive. Its results are combined
pairwise by the *reduce_function*, which receives two arguments. Unlike
calling map followed by reduce, no intermediate list is created. A range
containing a single value returns its mapped value directly.

  The order in which the mapped values are combined is not guaranteed,
so the reduce function must be associative.

  Topic: Tuples

  See also: std_types::value_range/std::map,
            std_types::value_range/std::reduce

  Example:

    map_reduce $sq_sum
      1..5
      : (n)
        -> times(n n)
      plus
    println! "sum of squares 1 to 5: @(sq_sum)"

  Output:

    sum of squares 1 to 5: 55
