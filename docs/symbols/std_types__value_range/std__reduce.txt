# std_types::value_range/std::reduce (a method)

  folds a value range into a single value by applying a binary function

  Parameters:
    self: the value range to reduce
    reduce_function: the function to apply to pairs of values

  Results:
    value: the reduced result

  The *reduce_function* is applied pairwise across every integer in the
range, from the lower bound to the upper bound, inclusive. A range
containing a single value returns that value directly.

  The order in which the values are combined is not guaranteed, so the
reduce function must be associative.

  Topic: Tuples

  See also: std_types::value_range/std::map,
            std_types::value_range/std::map_reduce

  Example:

    $sum_3_to_7 reduce(3..7 plus)
    println! "sum of 3 to 7: @(sum_3_to_7)"

  Output:

    sum of 3 to 7: 25
