# std_types::value_range/std::match (a method)

  matches a value range against the start of a string

  Parameters:
    self: the value range
    stream: the string to match against

  Results:
    length: 1 if the first character is within the range, undefined otherwise
    capture: undefined when requested as a second result

  Matches the first character of the given string against the value range. If
  the character falls within the range (inclusive on both ends), returns 1.
  Otherwise returns undefined.

  When called with two result destinations, a second undefined value is also
  returned.

  Topic: Tuples

  See also: std_types::value_range/std::match_back,
            std_types::value_range/std::search

  Example:

    $letters 'a'..'z'
    match $len letters "hello"
    if
      is_undefined(len)
      :
        println! "No match"
      :
        println! "Matched " len " character at the start"

  Output:

    Matched 1 character at the start
