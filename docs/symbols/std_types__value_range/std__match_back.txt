# std_types::value_range/std::match_back (a method)

  matches a value range against the end of a string

  Parameters:
    self: the value range
    str: the string to match against

  Results:
    length: 1 if the last character is within the range, undefined otherwise

  Matches the last character of the given string against the value range. If
  the character falls within the range (inclusive on both ends), returns 1.
  Otherwise returns undefined.

  Topic: Tuples

  See also: std_types::value_range/std::match,
            std_types::value_range/std::search

  Example:

    $letters 'a'..'z'
    match_back $len letters "hello"
    if
      is_undefined(len)
      :
        println! "Last character does not match the range"
      :
        println! "Last character matches the range"

  Output:

    Last character matches the range
