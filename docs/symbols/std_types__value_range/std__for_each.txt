# std_types::value_range/std::for_each (an I/O method)

  iterates over all items of a value range

  Parameters:
    self: the value range to iterate over
    body: the function to call for each item
    finally: the function to call after the iteration

  Results:
    the result(s) of the finally callback

  The *body* function is called once for every integer in the range, from
the lower bound to the upper bound, inclusive. To start the next
iteration a tail call to the *next* function has to be performed. The
loop is exited when the end of the range is reached without calling
*next*.

  **This function must be called with I/O-access rights!**

  Topic: Loops

  See also: std::next, std::break

  Example:

    $sum 0
    for_each !sum 1..10
      : (number)
        plus &sum number
        next
      -> sum
    println! "sum of 1 to 10: @(sum)"

  Output:

    sum of 1 to 10: 55
