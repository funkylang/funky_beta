# std_types::value_range/std::map (a method)

  applies a function to all values of a range and returns a list

  Parameters:
    self: the value range which items will be mapped
    function: the function to apply to each value of the range

  Results:
    list: a list of the "mapped" items

  The *function* is called once for every integer in the range, from the
lower bound to the upper bound, inclusive, and receives the current
value as its single argument. The results are collected into a new
list in order, which is returned.

  Topic: Tuples

  See also: std_types::value_range/std::reduce,
            std_types::value_range/std::map_reduce

  Example:

    map $squares
      1..6
      : (n)
        -> times(n n)
    debug::dump 99 `squares

  Error output:

    squares:
      list
        1
        4
        9
        16
        25
        36
