# std_types::value_range/std::search (a method)

  searches for a character matching a value range in a string

  Parameters:
    self: the value range
    str: the string to search
    nth?: which occurrence to find (default 1)

  Results:
    pos: the one-based position of the match, or undefined on failure
    len: always 1 when a match is found

  Scans the string for characters within the specified value range. Returns
  the position and length (always 1) of the matching character, or undefined
  for both if no match is found.

  Topic: Tuples

  See also: std_types::value_range/std::match,
            std_types::value_range/std::match_back

  Example:

    $letters 'a'..'z'
    search $pos _len letters "123abc"
    if
      is_undefined(pos)
      :
        println! "No letter found"
      :
        println! "First letter at position " pos

  Output:

    First letter at position 4
