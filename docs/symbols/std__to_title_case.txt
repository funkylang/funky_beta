# std::to_title_case (a polymorphic function)

  converts the contents to Title Case

  Parameter:
    string: the string to be converted

  Result:
    title: the title case version of the string

  The first character of each word is converted to upper case and all other
  characters to lower case.

  Topic: Strings

  See also: std::to_lower_case, std::to_upper_case

  Example:

    $s "hello world from funky"
    println! s.to_title_case

  Output:

    Hello World From Funky
