# std_types::insert_order_table/std::first_item_of (a method)

  returns the first-inserted value of a non-empty insert-order table

  Parameter:
    self: an insert-order table

  Result:
    value: the value that was inserted first, or an error if the table is empty

  An insert-order table remembers in which order its entries were
  added. This method returns the value of the entry that was added
  first, independent of any ordering of the keys themselves.

  Topic: Tables

  See also: std_types::insert_order_table/std::last_item_of,
            std_types::insert_order_table/std::first_key_of,
            std_types::insert_order_table/std::last_key_of

  Example:

    $prices insert_order_table("coffee" = 1200 "tea" = 850)
    add &prices "cocoa" = 1600
    println! "first inserted item: @(first_item_of(prices))"
    println! "last inserted item: @(last_item_of(prices))"

  Output:

    first inserted item: 1200
    last inserted item: 1600
