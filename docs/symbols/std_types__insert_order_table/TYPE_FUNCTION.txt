# std_types::insert_order_table/: (a type function)

  retrieve, insert, or delete a key-value pair while preserving insertion order

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    result: the stored value (retrieve) or modified table (insert/delete)

  Calling a <std_types::insert_order_table> with a single key retrieves
  the associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a clone of the table. Keys must support comparison via
  <equal>. Unlike other table types, this variant preserves insertion
  order, making iteration return entries in the order they were added.
  Internally, parallel arrays store keys and values separately, with a
  hash index mapping keys to array positions for fast lookup.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a clone with length decreased by one. Attempting
  to delete a non-existent key returns an unchanged clone.

  Topic: Tables

  See also: std::empty_insert_order_table, std_types::insert_order_table
