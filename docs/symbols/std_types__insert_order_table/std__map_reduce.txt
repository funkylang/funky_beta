# std_types::insert_order_table/std::map_reduce (a method)

  combines a map and a reduce operation into a single operation

  Parameters:
    self: the insert order table to work on
    map_function: the function to apply to each element of the table
    reduce_function?: combines pairs of values (defaults to <append>)
    unit?: the value returned for an empty table (defaults to <undefined>)

  Results:
    the reduced result

  Does not create an intermediate table to hold the "mapped" values.

  Topic: Tables

  See also: std_types::insert_order_table/std::map,
            std_types::insert_order_table/std::reduce

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/insert_order_table>
    
    $stock empty_insert_order_table
    !stock("apples") 10
    !stock("pears") 20
    map_reduce $total
      stock
      : (name quantity)
        -> times(quantity length_of(name))
      : (a b)
        -> a+b
      0
    println! "total: @(total)"
