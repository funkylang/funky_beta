# std_types::insert_order_table/std::map_reduce (a method)

  combines map and reduce into a single pass over an insert order table

  Parameters:
    self: the insert order table to work on
    map_function: a function that transforms each key-value pair
    reduce_function?: a two-argument combine function (defaults to <append>)
    unit?: the value to return for an empty table

  Results:
    result: the reduced result after mapping

  Unlike calling map followed by reduce, no intermediate table is created.
The map callback may accept one argument (the value) or two arguments
(key and value). The reduction order is not guaranteed, so the combine
function must be associative. A single-element table returns the mapped
value directly. The unit value is only consumed when the table is empty.

  Topic: Tables

  See also: std_types::insert_order_table/std::map,
            std_types::insert_order_table/std::reduce

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/insert_order_table>

    $stock empty_insert_order_table
    !stock("apples") 10
    !stock("pears") 20
    map_reduce $total
      stock
      : (name quantity)
        -> times(quantity length_of(name))
      plus
    println! "total: @(total)"

  Output:

    total: 160
