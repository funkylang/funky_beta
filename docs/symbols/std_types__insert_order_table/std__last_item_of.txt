# std_types::insert_order_table/std::last_item_of (a method)

  returns the last-inserted value of a non-empty insert-order table

  Parameter:
    self: an insert-order table

  Result:
    value: the value that was inserted last, or an error if the table is empty

  An insert-order table remembers in which order its entries were
  added. This method returns the value of the entry that was added
  last, independent of any ordering of the keys themselves.

  Topic: Tables

  See also: std_types::insert_order_table/std::first_item_of,
            std_types::insert_order_table/std::first_key_of,
            std_types::insert_order_table/std::last_key_of

  Example:

    $prices insert_order_table("coffee" = 1200 "tea" = 850)
    println! "last inserted item: @(last_item_of(prices))"
    add &prices "cocoa" = 1600
    println! "after adding cocoa: @(last_item_of(prices))"

  Output:

    last inserted item: 850
    after adding cocoa: 1600
