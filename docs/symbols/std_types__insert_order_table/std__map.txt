# std_types::insert_order_table/std::map (a method)

  applies a function to all values of the insert order table

  Parameters:
    self: the insert order table whose values will be mapped
    function: the function to apply to each element

  Result:
    an insert order table containing the mapped values

  Returns a cloned insert order table with each value transformed by the
  function; the original table remains unchanged. The function is dispatched
  based on its parameter count.

  **Two parameters:** the function receives the key and the value for each
  item, allowing the transformation to depend on the key.

  **One parameter:** the function receives only the value; the key is not
  passed.

  The function applications may be executed in parallel. The callback is
  invoked without I/O-access rights.

  Topic: Tables

  See also: std_types::insert_order_table/std::reduce,
            std_types::insert_order_table/std::map_reduce

  Example:

    $ages empty_insert_order_table
    !ages("John") 42
    !ages("Mary") 25
    !ages("Irene") 49

    $double: (v)
      times v 2

    map $result ages double
    debug::dump 99 `result

        "Mary" = 50
        "Irene" = 98
