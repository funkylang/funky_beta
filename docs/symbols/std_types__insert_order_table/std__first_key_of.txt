# std_types::insert_order_table/std::first_key_of (a method)

  returns the first-inserted key of a non-empty insert-order table

  Parameter:
    self: an insert-order table

  Result:
    key: the key that was inserted first, or an error if the table is empty

  An insert-order table remembers in which order its entries were
  added. This method returns the key of the entry that was added
  first, independent of any ordering of the keys themselves.

  Topic: Tables

  See also: std_types::insert_order_table/std::last_key_of,
            std_types::insert_order_table/std::first_item_of,
            std_types::insert_order_table/std::last_item_of

  Example:

    $scores insert_order_table("math" = 90 "physics" = 78)
    println! "first inserted key: @(first_key_of(scores))"
    add &scores "chemistry" = 85
    println! "last inserted key: @(last_key_of(scores))"

  Output:

    first inserted key: math
    last inserted key: chemistry
