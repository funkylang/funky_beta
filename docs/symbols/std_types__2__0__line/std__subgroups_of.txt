# std_types::2::0::line/std::subgroups_of (a method)

  returns the empty list of subgroups for a plain line

  Parameter:
    _self: the line object

  Result:
    subgroups: empty list

  A line without children always returns an empty list. Only
  <std_types-2.0::group> objects have non-empty subgroups. This method
  enforces that constant behaviour.

  Topic: Strings

  See also: std-2.0::split_into_groups, std_types-2.0::line

  Example:

    <using std-2.0>

    $text "
      a
        1
        2
      b
        3
        4
    $lines split_into_indented_lines(text)
    $sub subgroups_of(lines(1))
    dump! `length_of(sub)

  Output:

    length_of(sub): 0
