# std_types::2::0::line/std::indent_of (an attribute)

  the indentation level of a line in column positions

  Records how many column positions of leading whitespace preceded
  the text. Spaces count as 1, tabs as 8. Set by
  <std-2.0::split_into_indented_lines>.

  Topic: Strings

  See also: std-2.0::indent_of, std_types-2.0::line

  Example:

    <using std-2.0>

    $text "
      a
        1
        2
      b
        3
        4
    $lines split_into_indented_lines(text)
    $line2 lines(2)
    dump! `indent_of(line2)

  Output:

    indent_of(line2): 2
