# std_types::2::0::line/std::text_of (an attribute)

  the text content of a line without indentation or newline

  Stores the line text excluding leading whitespace and the terminating
  newline character. Set by <std-2.0::split_into_indented_lines>.

  Topic: Strings

  See also: std-2.0::text_of, std_types-2.0::line

  Example:

    <using std-2.0>

    $text "
      a
        1
        2
      b
        3
        4
    $lines split_into_indented_lines(text)
    $line2 lines(2)
    dump! `text_of(line2)
