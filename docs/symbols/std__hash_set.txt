# std::hash_set (a function)

  creates a hash set from a list of keys

  Parameters:
    keys*: the keys to insert into the set

  Result:
    a hash set containing the keys, in arbitrary order

  The keys must support the hash and equal methods. Duplicate keys
  are collapsed, so the set contains each key at most once.

  Topics: Sets, Collections

  See also: std::empty_hash_set, std_types::hash_set

  Example:

    $friends hash_set("Alice" "Bob" "Carol")
    dump! `friends

  Output:

    friends: hash_set <3>
      "Bob"
      "Alice"
      "Carol"
