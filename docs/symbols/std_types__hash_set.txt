# std_types::hash_set (a type derived from std_types::object)

  a set for fast random access

  All items stored in the set must support the following methods:

  * <hash>

  * <equal>

  Membership tests and iteration order are arbitrary. The set is
  the fastest of the three kinds for large numbers of items.

  Topics: Sets, Collections

  See also: std_types::set, std_types::key_order_set,
            std_types::insert_order_set, std_types::hash_table

  Example:

    $friends empty_hash_set
    !friends("Alice") true
    !friends("Bob") true
    $present friends("Bob")
    dump! `present

  Output:

    present: <true>
