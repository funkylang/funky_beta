# std::from_utf8 (a polymorphic function)

  converts a UTF-8 encoded octet string to a string

  Parameter:
    bytes: the UTF-8 encoded byte sequence

  Result:
    string: the decoded string

  The resulting string is a list of Unicode codepoints, each representing
  one character. Multi-byte UTF-8 sequences are decoded into their corresponding
  Unicode codepoints.

  Topic: Text

  See also: std::to_utf8, std::is_an_octet_string

  Example:

    $str "äöü"
    $utf8_str str.to_utf8
    $funky_str utf8_str.from_utf8
    println! "UTF8 length: " length_of(utf8_str)
    println! "Funky length: " length_of(funky_str)

  Output:

    UTF8 length: 6
    Funky length: 3
