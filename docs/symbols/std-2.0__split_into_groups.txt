# std-2.0::split_into_groups (a function)

  groups lines into a hierarchy based on indentation

  Parameters:
    lines: list of <std_types-2.0::line> objects
    keep_empty_lines?: if true, retain empty lines in the grouping
    split_recursively?: if true, use parallel recursive splitting
    proto_group?: prototype type for groups (default <std_types-2.0::group>)

  Result:
    groups: list of groups and lines organized by indentation level

  Lines with greater indentation than their predecessor become subgroups
  nested under the less-indented header line. The result is a list of
  <std_types-2.0::group> objects and plain lines at the top level.

  Topic: Strings

  See also: std-2.0::split_into_indented_lines, std_types-2.0::group

  Example:

    <using std-2.0>

    $text "
      a
        1

        2
      b
        3
        4
    $lines split_into_indented_lines(text)
    $groups split_into_groups(lines)
    debug::dump 99 `groups
