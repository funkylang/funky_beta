# llama::MODEL_NAME (a unique item)

  the model name option for llama-server completion requests

Use as a key in the options of <llama::complete> to specify which GGUF model
on the server should process the request. Pass the path or alias of the model
as the value. When omitted or set to <undefined>, the server uses its currently
loaded default model.

  Topic: AI

  See also: llama::complete, llama::MAX_TOKENS, llama::TEMPERATURE

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "What is 2+2"
      MAX_TOKENS = 3
      TEMPERATURE = 0

    println! result
