# std::date_and_time (a function)

  constructs a date-and-time object from calendar components

  Parameters:
    year: an integer year (1970 or later)
    month: an integer month (1-12)
    day: an integer day (1-31)
    hour: an integer hour (0-23)
    minute: an integer minute (0-59)
    second: a real second (0-59.999999999)
    time_shift: an integer timezone offset in seconds from UTC

  Result:
    value: a date-and-time object

  Takes year, month, day, hour, minute, and second as arguments and
  creates a date-and-time object. An optional seventh argument specifies
  the local timezone offset in seconds from UTC -- when omitted, the
  system timezone is used.

  Returns <std::undefined> when any component is out of valid range:
  year before 1970, month outside 1-12, day exceeding the month length,
  hour outside 0-23, minute outside 0-59, or seconds outside 0-59. Leap
  years and variable month lengths are handled automatically.

  Topic: Date and Time

  See also: std::from_unix_time, std::current_time, std_types::date_and_time

  Example:

    $t date_and_time(2024 1 1 12 0 0)
    println! t

  Output:

    2024-01-01 13:00:00.000 GMT+1
