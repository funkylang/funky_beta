# std_types::set (a type derived from std_types::collection)

  the prototype object for all kinds of sets

  A set is a collection of unique values. Calling a set with a
  single key returns <std::true> if the key is present,
  <std::false> otherwise.

  With two arguments, it modifies the set. The second argument
  must be a boolean. If it is <std::true>, the key is added to
  the set. If it is <std::false>, the key is removed from the
  set. In both cases a cloned set is returned and the original
  set remains unchanged. If the key's state is not actually
  changed, the original set is returned unchanged.

  There are three concrete kinds of sets. A hash set offers fast
  membership tests in arbitrary order. A key order set keeps its
  items sorted by their keys. An insert order set keeps its items
  in the order in which they were inserted.

  Topics: Sets, Collections

  See also: std_types::table

  Example:

    $friends empty_hash_set
    !friends("Alice") true
    !friends("Bob") true
    !friends("Carol") true
    $present friends("Bob")
    dump! `present
    $grown friends("Dave" true)
    $reduced friends("Bob" false)
    dump! `grown `reduced

  Output:

    present: <true>
    grown: hash_set <4>
      "Dave"
      "Bob"
      "Alice"
      "Carol"
    reduced: hash_set <2>
      "Alice"
      "Carol"
