# std_types::key_order_table/std::merge (a method)

  merges two key-order tables, other wins on duplicate keys

  Parameters:
    self: the base table
    other: the table to merge in

  Result:
    table: a new key-order table containing the entries of both

  Merges the base table with another table. If a key is contained in
  both tables, the value from the *other* table is used for the merged
  table. The result is a new key-order table; neither input table is
  changed.

  Topic: Tables

  See also: std_types::key_order_table/std::map_reduce,
            std_types::key_order_table/std::reduce

  Example:

    $base key_order_table("apple" = 5 "banana" = 3 "cherry" = 8)
    $extra key_order_table("banana" = 99 "date" = 4)
    $combined merge(base extra)
    for_each! combined
      : (fruit count)
        println! fruit ": " count
        next!
      pass

  Output:

    apple: 5
    banana: 99
    cherry: 8
    date: 4
