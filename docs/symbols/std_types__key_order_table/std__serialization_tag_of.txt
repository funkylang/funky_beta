# std_types::key_order_table/std::serialization_tag_of (an attribute)

  the string used to identify key-order tables when serialized

  Parameter:
    self: a key-order table

  Result:
    tag: the serialization tag, the string "key_order_table"

  The serialization tag identifies this type in serialized text. It is
  used by std::serialize to mark every key-order table in the output
  and by std::deserialize to know which deserializer to apply when
  reading it back.

  Topics: Collections, Serialization

  See also: std::serialize, std::deserialize

  Example:

    $tag serialization_tag_of(std_types::key_order_table)
    println! "serialization tag: @(tag)"
    $text serialize(std::empty_key_order_table)
    println! "serialized empty table: @(text)"

  Output:

    serialization tag: key_order_table
    serialized empty table: key_order_table <0>
