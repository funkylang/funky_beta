# std_types::key_order_table/: (a type function)

  retrieve, insert, or delete a key-value pair in key order

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    result: the stored value (retrieve) or modified table (insert/delete)

  Calling a <std_types::key_order_table> with a single key retrieves
  the associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a clone of the table. Keys must support comparison via
  <less> and <equal> operators. Entries are maintained in sorted key
  order using a binary search tree structure.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a clone with the entry removed. Attempting to
  delete a non-existent key returns an unchanged clone.

  Topic: Tables

  See also: std::empty_key_order_table, std_types::key_order_table

  Example:

    $scores empty_key_order_table
    !scores("math") 95
    !scores("english") 88
    !scores("science") 91
    println! scores("english")
    !scores("english") undefined
    println! length_of(scores)

  Output:

    88
    2
