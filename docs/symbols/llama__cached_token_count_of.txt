# llama::cached_token_count_of (a polymorphic function)

  the number of prompt tokens served from the server's KV cache

  Parameters:
    meta: a llama_types::metadata object from llama::complete

  Result:
    count: an integer, or undefined if not yet reported

  How many prompt tokens were served from the server's KV cache rather than
  being recomputed. A high cached count indicates efficient reuse of context
  across requests; useful for monitoring cache hit rates on long
  conversations or repeated prompts. The value is only populated when the
  server supports and reports cache statistics.

  Topic: AI

  See also: llama_types::metadata, llama::CACHE_PROMPT

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Hello there!"
      METADATA
      CACHE_PROMPT
      MAX_TOKENS = 10
      TEMPERATURE = 0

    println! "Cached tokens: " debug::to_string(cached_token_count_of(meta) 0 1)

  Output:

    Cached tokens: 4
