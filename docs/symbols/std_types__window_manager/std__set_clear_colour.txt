# std_types::window_manager/std::set_clear_colour (a method)

  sets the clear colour of a window

  Parameters:
    wm: the window manager
    id: the id of the window (optional)
    colour: the new clear colour

  Result:
    wm: the updated window manager

  If the window id is omitted the focused window is used.

  The clear colour is used to clear the window's content area.
