# std::start_injecting_window_change_events (a polymorphic function)

  inject SIGWINCH signals as events into the I/O event loop

  When the terminal window is resized, the operating system sends a SIGWINCH signal.
  Calling this function registers a signal handler so that each SIGWINCH is converted
  into a window change event delivered through the I/O event loop. This allows
  applications to react to resize events without polling the terminal size.

  To stop receiving window change events, call `std::stop_injecting_window_change_events`.

  Parameters:
    io: the I/O object

  Topic: Input-Output Events

  See also: std::stop_injecting_window_change_events, std::start_catching_signals
