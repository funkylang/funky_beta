# std-2.0::text_of (a polymorphic function)

  returns the text content of a line object without indentation

  Parameter:
    line: a <std_types-2.0::line> object

  Result:
    text: the string content with leading whitespace removed

  Returns the text of the line, excluding any leading spaces or tabs
  and the terminating newline character. The indentation level is tracked
  separately via <std-2.0::indent_of>.

  Topic: Strings

  See also: std-2.0::indent_of, std-2.0::split_into_indented_lines

  Example:

    <using std-2.0>

    $text "  hello@nl;"
    $lines split_into_indented_lines(text)
    $line1 lines(1)
    $content text_of(line1)
    dump! `content

  Output:

    content: "hello"
