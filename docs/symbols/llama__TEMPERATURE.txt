# llama::TEMPERATURE (a unique item)

  the temperature option for llama-server completion requests

Use as a key in the options of <llama::complete> to control sampling randomness.
Lower values produce more deterministic output; higher values add variety.
A value of 0 yields the most predictable results. When omitted, the server
uses its default temperature.

  Topic: AI

  See also: llama::complete, llama::TOP_K, llama::TOP_P

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "The capital of France is"
      TEMPERATURE = 0
      MAX_TOKENS = 3

    println! result

  Output:

    Paris.
