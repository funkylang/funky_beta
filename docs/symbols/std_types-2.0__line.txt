# std_types-2.0::line (an object)

  a line from indented text with tracked indentation

  A line object holds two attributes: <std-2.0::indent_of> records the
  leading indentation in column positions (spaces count as 1, tabs as 8),
  and <std-2.0::text_of> holds the text content excluding the indentation
  and the terminating newline.

  Created by <std-2.0::split_into_indented_lines>. The subtype
  <std_types-2.0::group> adds a <std::subgroups_of> attribute.

  Topic: Strings

  See also: std_types-2.0::group, std-2.0::indent_of, std-2.0::text_of

  Example:

    <using std-2.0>

    $text "
      a
        1
        2
      b
        3
        4
    $lines split_into_indented_lines(text)
    $line1 lines(1)
    dump! `indent_of(line1) `text_of(line1)

  Output:

    indent_of(line1): 0
    text_of(line1): "a"
