# std::list (a function)

  constructs a list from its arguments

  Parameter:
    args*: zero or more items to place in the list

  Result:
    list: an ordered sequence containing the arguments in order

  When called with no arguments, returns the empty list (std::empty_list).

  Lists are ordered, enumerated sequences of items. Items are accessed with
  one-based indexing: lst(1) returns the first item, lst(-1) the last.
  Lists are immutable - modifying a list produces a new list that shares
  structure with the original to avoid unnecessary data copying.

  Topic: Lists

  See also: std_types::list/std::new, std::append, std::empty_list

  Example:

    $empty list()
    $nums list(1 2 3 4 5)
    println! nums(1)    # 1
    println! nums(-1)   # 5
    $with_fourth nums(4 999)
