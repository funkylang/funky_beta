# std::initialized_array (a function)

  constructs an N-dimensional array with all elements
  initialized to the same value

  All arguments except the last specify the dimensions of
  the array. The final argument is the initial value
  assigned to every element. At least one dimension and
  the initial value are required.

  Parameters:
    dimension_1: the size of the first dimension
    ...
    dimension_n?: the size of additional dimensions
    initial_value: the value for all elements

  Results:
    an N-dimensional array with all elements initialized
    to initial_value

  Topic: Arrays

  See also: std::array, std::empty_array, std_types::array/new

  Example:

    $print_array: (data)
      $row_count length_of(data 1)
      $column_count length_of(data 2)
      $separator_line append("+" dup("---------+" column_count))
      println! separator_line
      from_to 1 row_count
        : (row_no)
          print! "|"
          from_to 1 column_count
            : (col_no)
              $val data(row_no col_no)
              print! pad_left(val 9) "|"
              next!
          println!
          println! separator_line
          next!
        pass

    $matrix initialized_array(3 4 42)
    print_array! matrix
