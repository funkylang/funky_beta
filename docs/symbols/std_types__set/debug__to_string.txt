# std_types::set/debug::to_string (a method)

  returns a string representation of a set

  Parameters:
    self: the set to convert
    indent?: current indentation level (default 0)
    depth?: nesting depth for collections (default 1)

  Results:
    a single line at depth 1 (terminated by a line feed), or a multi-line
    indented representation at greater depths

  At depth 1 (the default) an empty set returns "empty_<tag>" and a non-empty
  set returns "<tag with N items>". Both are terminated by a line feed. At depth
  greater than 1 the set is expanded: each element appears on its own indented
  line, with the serialization tag closing the block.

  Topic: Collections

  See also: std_types::set/std::serialize

  Example:

    $cities std::empty_hash_set
    !cities("Paris") true
    !cities("Tokyo") true
    !cities("London") true
    print! "Cities: " trim_left(debug::to_string(cities 0 3))

    $empty std::empty_hash_set
    print! "Empty set: " trim_left(debug::to_string(empty 0 3))

  Output:

    Cities: hash_set
      "Tokyo"
      "London"
      "Paris"
    Empty set: empty_hash_set
