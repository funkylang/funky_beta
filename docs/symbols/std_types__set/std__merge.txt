# std_types::set/std::merge (a method)

  combines the elements of two sets into one

  Parameters:
    self: the base set
    other: another set whose elements are added

  Results:
    a new set containing all elements from both input sets

  Copies the first set and adds every element from the second. Elements that
  already exist are not duplicated. The result has the same type as self.

  Topic: Collections

  See also: std_types::set/std::intersection, std_types::set/std::serialize

  Example:

    $berries std::empty_key_order_set
    !berries("strawberry") true
    !berries("blueberry") true

    $citrus std::empty_key_order_set
    !citrus("lemon") true
    !citrus("orange") true

    $all_fruits merge(berries citrus)
    print! "All fruits: " trim_left(debug::to_string(all_fruits 0 3))

  Output:

    All fruits: key_order_set
      "blueberry"
      "lemon"
      "orange"
      "strawberry"
