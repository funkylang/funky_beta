# std_types::set/std::to_list (a method)

  returns all elements of a set as a list

  Parameters:
    self: the set to convert

  Results:
    a list containing all elements from the set

  Iterates over the set and pushes each element into a new list. The iteration
  order depends on the underlying set type: arbitrary for hash sets, sorted for
  key_order_set, insertion order for insert_order_set.

  Topic: Collections

  See also: std_types::set/std::serialize, std_types::list/std::to_string

  Example:

    $fruits std::empty_key_order_set
    !fruits("apple") true
    !fruits("banana") true
    !fruits("cherry") true

    $fruit_list to_list(fruits)
    print! "Fruit list: " trim_left(debug::to_string(fruit_list 0 2))

  Output:

    Fruit list: list
      "apple"
      "banana"
      "cherry"
