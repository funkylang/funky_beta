# std_types::set/std::is_a_set (an attribute)

  checks if an object is a set

  Parameters:
    none

  Results:
    true for set types, false otherwise

  This polymorphic attribute returns <true> when the object is a set and <false>
  for all other types. Use it to check whether a value is a set at runtime.

  Topic: Collections

  See also: std::is_a_set

  Example:

    $fruits std::empty_key_order_set
    !fruits("apple") true
    if
      is_a_set(fruits)
      : println! "fruits is a set."
      : println! "fruits is not a set."

    if
      is_a_set(42)
      : println! "42 is a set."
      : println! "42 is not a set."

  Output:

    fruits is a set.
    42 is not a set.
