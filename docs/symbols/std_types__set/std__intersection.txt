# std_types::set/std::intersection (a method)

  returns the common elements shared by two sets

  Parameters:
    self: a set
    other: another set to intersect with

  Results:
    a new set of the same type as self with only elements present in both sets

  Iterates over the first set and keeps those elements that also exist in the
  second. The result has the same type as the first argument. If no elements are
  shared, returns an empty set.

  Topic: Collections

  See also: std_types::set/std::merge, std_types::set/std::serialize

  Example:

    $fruits std::empty_key_order_set
    !fruits("apple") true
    !fruits("banana") true
    !fruits("cherry") true

    $tropical std::empty_key_order_set
    !tropical("banana") true
    !tropical("mango") true
    !tropical("papaya") true

    $common intersection(fruits tropical)
    print! "Common items: " trim_left(debug::to_string(common 0 3))

  Output:

    Common items: key_order_set
      "banana"
