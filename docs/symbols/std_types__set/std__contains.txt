# std_types::set/std::contains (a method)

  checks if one set contains all items of another set

  Parameters:
    self: the set to check in
    other: the set whose items are looked for

  Results:
    true if every item in other is also in self, false otherwise

  Checks every item of the other set and returns <true> only if all of them
  exist in the set. It returns <false> as soon as the first missing item is
  found. Since an empty set has no items, any set contains the empty set.

  Topic: Collections

  See also: std_types::set/std::merge, std_types::set/std::intersection

  Example:

    $warehouse std::empty_hash_set
    !warehouse("Steel") true
    !warehouse("Copper") true
    !warehouse("Plastic") true
    print! "Warehouse: " trim_left(debug::to_string(warehouse 0 3))

    $parts std::empty_hash_set
    !parts("Steel") true
    !parts("Copper") true
    print! "Parts: " trim_left(debug::to_string(parts 0 3))

    println! ""

    if
      contains(warehouse parts)
      :
        println! "All parts are in stock."
      :
        println! "Some parts are missing from the warehouse."

  Output:

    Warehouse: hash_set
      "Steel"
      "Copper"
      "Plastic"
    Parts: hash_set
      "Steel"
      "Copper"

    All parts are in stock.

  Example:

    $available std::empty_hash_set
    !available("Apple") true
    !available("Banana") true
    print! "Available: " trim_left(debug::to_string(available 0 3))

    $wanted std::empty_hash_set
    !wanted("Guava") true
    print! "Wanted: " trim_left(debug::to_string(wanted 0 3))

    println! ""

    if
      contains(available wanted)
      :
        println! "All wanted items are available."
      :
        println! "Some wanted items are out of stock."

    $empty std::empty_hash_set
    print! "Empty set: " trim_left(debug::to_string(empty 0 3))

    if
      contains(available empty)
      :
        println! "An empty set is always contained."
      :
        println! "Unexpected: empty set not contained."

  Output:

    Available: hash_set
      "Apple"
      "Banana"
    Wanted: hash_set
      "Guava"

    Some wanted items are out of stock.
    Empty set: empty_hash_set
    An empty set is always contained.
