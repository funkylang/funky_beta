# std_types::set/std::deserializer_of (a method)

  returns a deserializer function for reconstructing sets from serialized data

  Parameters:
    type: the concrete set type (e.g. empty_key_order_set)
    items: parsed item data from the serialization framework

  Results:
    a new set of the specified type containing all items

  This method is used internally by the serialization framework. To deserialize
  a set from its serialized form, call <deserialize>.

  Only concrete set types registered with the deserializers framework can be
  deserialized: key_order_set and insert_order_set. The base hash_set is not.

  Topic: Serialization

  See also: std::deserialize, std_types::set/std::serialize

  Example:

    $fruits std::empty_key_order_set
    !fruits("apple") true
    !fruits("banana") true
    !fruits("cherry") true

    $serialized serialize(fruits)
    print! "Original: " trim_left(debug::to_string(fruits 0 3))
    println! ""

    deserialize $restored serialized
    print! "Restored: " trim_left(debug::to_string(restored 0 3))

  Output:

    Original: key_order_set
      "apple"
      "banana"
      "cherry"

    Restored: key_order_set
      "apple"
      "banana"
      "cherry"
