# std_types::set/std::equal (a method)

  checks if two sets contain the same elements

  Parameters:
    self: a set
    other: another set to compare against

  Results:
    true if both sets have identical contents, false otherwise

  Two sets are equal if they contain the same elements. The iteration order does
  not matter. If the lengths differ, the comparison returns <false> immediately.
  Otherwise every element of the first set is looked up in the second.

  Topic: Collections

  See also: std_types::set/std::intersection, std_types::set/std::serialize

  Example:

    $fruits std::empty_key_order_set
    !fruits("apple") true
    !fruits("banana") true
    !fruits("cherry") true

    $more_fruits std::empty_key_order_set
    !more_fruits("cherry") true
    !more_fruits("apple") true
    !more_fruits("banana") true

    if
      fruits == more_fruits
      : println! "Both sets contain the same fruits."
      : println! "The sets differ."

  Output:

    Both sets contain the same fruits.
