# std_types::hash_table/std::reduce (a method)

  folds a table into a single value by repeatedly applying a binary function

  Parameters:
    self: the table to reduce
    reduce_function: the function to apply to pairs of values
    unit?: the value to return for an empty table

  Results:
    value: the reduced result

  The reduction order is not guaranteed, so the combine function must be
associative. A single-element table returns that element's value directly.
The unit value is only consumed when the table is empty.

  Topic: Tables

  See also: std_types::hash_table/std::map,
            std_types::hash_table/std::map_reduce

  Example:

    $cart hash_table("apples" = 10 "oranges" = 15 "bananas" = 3)
    $total reduce(cart plus)
    println! "total items: " total

  Output:

    total items: 28
