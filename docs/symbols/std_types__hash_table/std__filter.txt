# std_types::hash_table/std::filter (a method)

  keeps only the entries for which the given function returns true

  Parameters:
    self: the table to work on
    function: the function to check for each element of the table

  Result:
    table: the filtered table

  The function receives either one argument (the value) or two
  arguments (the key and the value). An element is kept in the new
  table if the function returns true for it.

  If no entry meets the condition, or none at all was deleted, the
  original table is returned unchanged; otherwise a cloned table with
  the remaining entries is returned and the original table remains
  unchanged.

  Topic: Tables

  See also: std_types::hash_table/std::map, std_types::hash_table/std::reduce,
            std_types::hash_table/std::map_reduce

  Example:

    $ages hash_table("alice" = 30 "bob" = 41 "carol" = 25)

    # one-argument form receives the value
    $young filter(ages : (age) -> age < 40)
    println! "younger than 40: @(length_of(young)) entries"

    # two-argument form receives key and value
    $under_35 filter(ages : (name age) -> name == "carol" && age < 35)
    println! "selected: @(length_of(under_35)) entries"
    dump! `young `under_35

  Output:

    younger than 40: 2 entries
    selected: 1 entries
    young: hash_table <4>
      "carol"
      25
      "alice"
      30
    under_35: hash_table <2>
      "carol"
      25
