# std_types::hash_table/std::map (a method)

  applies a function to all values of the hash table

  Parameters:
    self: the hash table whose values will be mapped
    function: the function to apply to each element

  Result:
    a hash table containing the mapped values

  Returns a cloned hash table with each value transformed by the function;
  the original table remains unchanged. The function is dispatched based
  on its parameter count.

  **Two parameters:** the function receives the key and the value for each
  item, allowing the transformation to depend on the key.

  **One parameter:** the function receives only the value; the key is not
  passed.

  The function applications may be executed in parallel. The callback is
  invoked without I/O-access rights.

  Topic: Tables

  See also: std_types::hash_table/std::reduce,
            std_types::hash_table/std::map_reduce

  Example:

    $ages
      hash_table
        "John" = 42
        "Mary" = 25
        "Irene" = 49

    $double: (v)
      times v 2

    map $result ages double
    debug::dump 99 `result

  Error output:

    result:
      hash_table
        "Mary" = 50
        "Irene" = 98
        "John" = 84
