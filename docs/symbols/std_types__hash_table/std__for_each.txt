# std_types::hash_table/std::for_each (an I/O method)

  invokes a callback for each key-value pair in a hash table

  Parameters:
    self: the hash table to iterate over
    body: the callback invoked for each item
    finally?: invoked after iteration ends; receives rebound variables
      from the body

  Results:
    the result(s) of the finally callback

  *This function propagates I/O-access rights to its callback body!*

  Iterates over all items in the hash table. Iteration order is undefined.
  The *body* callback is dispatched based on its parameter count.

  **Two parameters:** the callback receives the key and the value for
  each item.

  **One parameter:** the callback receives only the value; the key is not
  passed.

  To continue to the next iteration, the body must tail-call *next*. Use
  *next!* (with I/O suffix) when the body contains I/O calls, and *next*
  (without suffix) when it does not. Omitting the *next* call exits the loop
  early, equivalent to calling *break*.

  *break* exits the loop immediately and transfers control to the *finally*
  callback, passing along the current state of any rebound variables.

  The optional *finally* callback receives the final state of variables rebound
  inside the body. It is invoked whether iteration completes normally, exits
  via an early *next* omission, or is terminated by *break*. When the finally
  is omitted, *pass* (a no-op function) is used as the default.

  The *!* suffix on the outer *for_each* is handled implicitly by I/O
  propagation from the callback body.

  Topic: Tables

  See also: std::next, std::break, std::pass, std::keys_of, std::values_of

  Example:

    $ages
      hash_table
        "John" = 42
        "Mary" = 25
        "Irene" = 49

    for_each ages
      : (name age)
        println! "@(name): @(age) years"
        next!
      pass

  Output:

    Mary: 25 years
    Irene: 49 years
    John: 42 years

  Example:

    $prices
      hash_table
        "Apples" = 250
        "Bread" = 180
        "Cheese" = 320

    $total 0
    for_each !total prices
      : (price)
        plus &total price
        next
      -> total

    println! "Total: @(total) cents"

  Output:

    Total: 750 cents
