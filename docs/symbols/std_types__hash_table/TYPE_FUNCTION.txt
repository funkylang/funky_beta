# std_types::hash_table/: (a type function)

  retrieve, insert, or delete a key-value pair

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    result: the stored value (retrieve) or modified table (insert/delete)

  Calling a <std_types::hash_table> with a single key retrieves the
  associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a clone of the table with the new entry. If the key already
  exists, its value is replaced. The table length increases by one only
  when a new key is added.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a clone with length decreased by one. Deleting a
  non-existent key returns an unchanged clone.

  Internally, entries are stored in a hash-based tree structure with
  collision chaining. The hash index uses a sentinel bit to distinguish
  empty slots.

  Topic: Tables

  See also: std::empty_hash_table, std_types::hash_table

  Example:

    $names empty_hash_table
    !names("Alice") 30
    !names("Bob") 25
    println! names("Alice")
    !names("Alice") 31
    println! names("Alice")
    !names("Bob") undefined
    dump! `length_of(names)

  Output:

    30
    31
    length_of(names): 1
