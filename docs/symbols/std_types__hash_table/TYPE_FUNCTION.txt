# std_types::hash_table/: (a type function)

  retrieve, insert, or delete a key-value pair

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    the stored value on retrieval, or the modified table on insert/delete

  Calling a <std_types::hash_table> behaves differently depending on
  the number of arguments.

  **One argument:** the value is retrieved. The call returns the
  associated value, or <undefined> if the key is not present.

  **Two arguments:** the table is modified. The second argument is
  the new value to store. If the key already exists, its value is
  replaced; otherwise the entry is added and the table's length
  increases by one. A cloned table with the change is returned; the
  original table remains unchanged.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a cloned table with the entry removed; the original
  table remains unchanged. Deleting a non-existent key returns the
  original table unchanged.

  Topics: Tables, Collections

  See also: std::empty_hash_table, std_types::hash_set/:

  Example:

    $names empty_hash_table
    !names("Alice") 30
    !names("Bob") 25
    println! names("Alice")
    !names("Alice") 31
    println! names("Alice")
    !names("Bob") undefined
    println! length_of(names)

  Output:

    30
    31
    1
