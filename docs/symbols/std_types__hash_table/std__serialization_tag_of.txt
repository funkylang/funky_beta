# std_types::hash_table/std::serialization_tag_of (an attribute)

  the string used to identify hash tables when serialized

  Parameter:
    self: a hash table

  Result:
    tag: the serialization tag, the string "hash_table"

  The serialization tag identifies this type in serialized text. It is
  used by std::serialize to mark every hash table in the output and by
  std::deserialize to know which deserializer to apply when reading it
  back.

  Topics: Collections, Serialization

  See also: std::serialize, std::deserialize

  Example:

    $tag serialization_tag_of(std_types::hash_table)
    println! "serialization tag: @(tag)"
    $text serialize(std::empty_hash_table)
    println! "serialized empty table: @(text)"

  Output:

    serialization tag: hash_table
    serialized empty table: hash_table <0>
