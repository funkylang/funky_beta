# std_types::key_order_set/std::last_item_of (a method)

  returns the last item in the key order set

  Parameter:
    self: the key order set

  Result:
    the last (largest) item in the set, or undefined if the set
    is empty

  A key order set keeps its items sorted, so the last item is the
  largest one.

  Topic: Sets
