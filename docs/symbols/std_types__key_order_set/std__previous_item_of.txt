# std_types::key_order_set/std::previous_item_of (a method)

  returns the item that precedes a given key in the key order set

  Parameters:
    self: the key order set
    key: the key to start before

  Result:
    the largest item smaller than the key, or undefined if no
    such item exists

  Returns the previous item in sorted order. The key itself need not
  be a member of the set: the result is simply the largest item that
  is smaller than the key.

  Topic: Sets

  See also: std_types::key_order_set/std::first_item_of,
            std_types::key_order_set/std::last_item_of,
            std_types::key_order_set/std::next_item_of

  Example:

    $fruits key_order_set("apple" "banana" "cherry")
    println! "before banana: @(previous_item_of(fruits "banana"))"
    println! "before cherry: @(previous_item_of(fruits "cherry"))"

  Output:

    before banana: apple
    before cherry: banana
