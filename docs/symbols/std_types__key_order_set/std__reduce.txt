# std_types::key_order_set/std::reduce (a method)

  reduces a key order set into a single value

  Parameters:
    self: the key order set to work on
    reduce_function: the function to combine pairs of values
    unit?: the value to return for an empty set

  Result:
    the result of the reduction

  Combines all items in the set into a single value. The
  *reduce_function* receives two arguments — the accumulated result
  and the next item — and is applied pairwise across the set. When
  the set is empty, the *unit* value is returned.

  Topic: Sets

  See also: std_types::key_order_set/std::map_reduce,
            std_types::key_order_set/std::for_each

  Example:

    $prices key_order_set(250 180 320)
    $total reduce(prices plus)
    println! "Total: @(total) cents"

  Output:

    Total: 750 cents
