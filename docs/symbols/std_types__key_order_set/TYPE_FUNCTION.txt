# std_types::key_order_set/: (a type function)

  retrieve, add, or remove a key in key order

  Parameters:
    key: the lookup key
    value?: new state of the key (true to add, false to remove)

  Result:
    true or false on retrieval, or the modified set on add/remove

  Calling a <std_types::key_order_set> behaves differently depending
  on the number of arguments.

  **One argument:** the key's state is retrieved. The call returns
  <std::true> if the key is present, <std::false> otherwise.

  **Two arguments:** the set is modified. The second argument must be
  a boolean: <std::true> adds the key, <std::false> removes it. A
  cloned set with the change is returned; the original set remains
  unchanged. If the key's state is not actually changed, the original
  set is returned unchanged.

  Topics: Sets, Collections

  See also: std::empty_key_order_set, std_types::key_order_table/:

  Example:

    $days key_order_set("wednesday" "monday" "friday")
    $present days("monday")
    dump! `present
    $grown days("sunday" true)
    $reduced days("friday" false)
    dump! `grown `reduced

  Output:

    present: <true>
    grown: key_order_set <4>
      "friday"
      "monday"
      "sunday"
      "wednesday"
    reduced: key_order_set <2>
      "monday"
      "wednesday"
