# std_types::key_order_set/std::next_item_of (a method)

  returns the item that follows a given key in the key order set

  Parameters:
    self: the key order set
    key: the key to start after

  Result:
    the smallest item greater than the key, or undefined if no
    such item exists

  Returns the next item in sorted order. The key itself need not be
  a member of the set: the result is simply the smallest item that
  is greater than the key.

  Topic: Sets

  See also: std_types::key_order_set/std::first_item_of,
            std_types::key_order_set/std::last_item_of,
            std_types::key_order_set/std::previous_item_of

  Example:

    $fruits key_order_set("apple" "banana" "cherry")
    println! "after apple: @(next_item_of(fruits "apple"))"
    println! "after banana: @(next_item_of(fruits "banana"))"

  Output:

    after apple: banana
    after banana: cherry
