# std_types::float64_array/std::range (a method)

  creates a new float64 array with the elements in the given range

  Parameters:
    array: a float64 array
    ranges?: one or more value ranges, one per dimension

  Result:
    a new float64 array containing the selected elements

  The range argument is a value_range (start..end, inclusive). Supply one
range per dimension for multi-dimensional arrays. Returns a cloned array;
the original remains unchanged.

  Topic: Arrays

  See also: std::range, std_types::float64_array/std::length_of

  Example:

    $temps float64_array(6)
    !temps(1) 22.5
    !temps(2) 19.8
    !temps(3) 24.1
    !temps(4) 21.3
    !temps(5) 20.7
    !temps(6) 23.4

    $subset range(temps 2..5)
    println! "length: " length_of(subset)
    println! "first: " subset(1)
    println! "last: " subset(4)

  Output:

    length: 4
    first: 19.8
    last: 20.7
