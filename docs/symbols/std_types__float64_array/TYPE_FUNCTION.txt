# std_types::float64_array/: (a type function)

  gets or sets an element in a float64 array

Calling a <std_types::float64_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are 64-bit floating-point numbers.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged.

  Topic: Arrays

  See also: std_types::float64_array, std::empty_float64_array

  Example:

    $measurements float64_array(4)
    !measurements(1) 3.14159265
    !measurements(2) -0.5
    println! "First measurement: " measurements(1)

  Output:

    First measurement: 3.14159265
