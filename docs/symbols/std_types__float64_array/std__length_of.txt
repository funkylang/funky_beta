# std_types::float64_array/std::length_of (a method)

  returns the length of a dimension in a double-precision floating-point array

  Parameters:
    array: a float64 array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::float64_array/std::dimension_count_of

  Example:

    $temps float64_array(4)
    !temps(1) 22.5
    !temps(2) 19.8
    !temps(3) 24.1
    !temps(4) 21.3

    $len length_of(temps)
    println! "temperature count: " len

    $grid float64_array(2 3)
    println! "rows: " length_of(grid 1)
    println! "columns: " length_of(grid 2)

  Output:

    temperature count: 4
    rows: 2
    columns: 3
