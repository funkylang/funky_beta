# std_types::float64_array/std::equal (a method)

  compares two double-precision floating-point arrays element by element

  Parameters:
    left: a float64 array
    right: a float64 array

  Result:
    true if both arrays have the same shape and identical elements,
    false otherwise

  Two arrays are equal when they have matching dimensions and every
corresponding element holds the same value. Arrays with different
shapes always compare as unequal.

  Topic: Arrays

  See also: std::equal

  Example:

    $temps_a float64_array(3)
    !temps_a(1) 22.5
    !temps_a(2) 19.8
    !temps_a(3) 24.1

    $temps_b float64_array(3)
    !temps_b(1) 22.5
    !temps_b(2) 19.8
    !temps_b(3) 24.1

    $temps_c float64_array(3)
    !temps_c(1) 22.5
    !temps_c(2) 19.8
    !temps_c(3) 24.2

    if
      equal(temps_a temps_b)
      : println! "A and B are identical"
      : println! "A and B differ"

    if
      equal(temps_a temps_c)
      : println! "A and C are identical"
      : println! "A and C differ"

  Output:

    A and B are identical
    A and C differ
