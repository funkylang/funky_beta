# std::is_a_list (a polymorphic function)

  checks whether the given object is a list

  Parameter:
    self: the object to check

  Result:
    true if the object is a list, false otherwise

  Strings share part of the list implementation but are not lists themselves
  and return false.

  Topic: Lists

  See also: std::is_a_generic_list

  Example:

    $r1 is_a_list(list(1 2 3))
    $r2 is_a_list("hello")
    $r3 is_a_list(42)
