# llama::completion_token_count_of (a polymorphic function)

  the number of tokens in the generated output of a completion

  Parameters:
    meta: a llama_types::metadata object from llama::complete

  Result:
    count: an integer token count, or undefined if not yet reported

  How many tokens the model generated in response. Useful for monitoring
  output length, detecting early truncation, or estimating cost (on paid
  services). If this equals the MAX_TOKENS limit you passed, check
  llama::finish_reason_of to see whether the generation was cut off by the
  length constraint.

  Topic: AI

  See also: llama_types::metadata, llama::total_token_count_of

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ List five fruits."
      METADATA
      MAX_TOKENS = 20
      TEMPERATURE = 0.3

    println! "Completion tokens: "
        debug::to_string(completion_token_count_of(meta) 0 1)

  Output:

    Completion tokens: 20
