# std_types::generic_list/std::filter (a method)

  returns a collection of all items that fulfill the filter-condition

  Parameters:
    self: the collection to filter
    test: the filter-condition

  Results:
    good: the collection of items that fulfill the filter-condition
    bad: the collection of items that do not fulfill the filter-condition

  If the caller requests two result values then the items are divided into
  two collections: the first collection contains all items that fulfill the
  filter-condition; the second collection contains all items that do not
  fulfill the filter-condition.

  If the caller requests only one result value then the result is a
  collection containing all items that fulfill the filter-condition.

  Topic: Lists

  See also: std::map, std::find_first

  Example:

    $scores list(72 45 88 33 91 67)
    filter $passing
      scores
      : (s)
        -> s > 50
    debug::dump 99 `passing

  Error output:

    passing:
      list
        72
        88
        91
        67

  Example:

    $scores list(72 45 88 33 91 67)
    filter $passing $failing
      scores
      : (s)
        -> s > 50
    debug::dump 99 `passing `failing

  Error output:

    passing:
      list
        72
        88
        91
        67
    failing:
      list
