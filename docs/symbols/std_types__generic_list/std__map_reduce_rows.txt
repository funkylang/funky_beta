# std_types::generic_list/std::map_reduce_rows (a method)

  applies a map function to each row of a list of lists and then reduces the
  results using a reduce function.

  Parameters:
    self: the list of lists
    map_function: the function to apply to each row
    reduce_function: the function to apply to the results of the map function

  Result:
    a list containing the reduced results

  Each inner list is treated as a row. The map function is applied to
  every item of each row, and the resulting row is then reduced with the
  reduce function. One result is produced per row. Because the rows are
  reduced individually, the reduce function must be associative.

  Topic: Lists

  See also: std_types::generic_list/std::map_reduce_columns,
            std_types::generic_list/std::map

  Example:

    $print_list: (items)
      $count length_of(items)
      from_to! 1 count
        : (i)
          if
            i == 1
            : print! items(i)
            : print! " " items(i)
          next!
        pass
      println!

    $print_list_of_lists: (grid)
      for_each! grid
        : (row)
          print_list! row
          next!
        pass

    $scores list(list(1 2) list(3 4) list(5 6))
    println! "scores:"
    print_list_of_lists! scores
    map_reduce_rows $row_sums
      scores
      : (x) -> x*x
      plus
    debug::dump 99 `row_sums

    1 2
    3 4
