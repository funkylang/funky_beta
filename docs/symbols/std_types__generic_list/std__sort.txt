# std_types::generic_list/std::sort (a method)

  returns a sorted copy of the list

  Parameters:
    self: the list to sort
    compare: the comparison function

  Result:
    list: the sorted list

  If no comparison function is supplied then the items are sorted in ascending
  order using the <less>-method.

  Topic: Lists

  See also: std_types::generic_list/std::merge

  Example:

    $asc sort(marks)
    $desc sort(marks: (a b) -> a > b)
    debug::dump 99 `asc `desc
