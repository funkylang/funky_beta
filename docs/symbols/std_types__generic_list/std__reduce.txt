# std_types::generic_list/std::reduce (a method)

  folds a list into a single value by repeatedly applying a binary function

  Parameters:
    self: the list to reduce
    reduce_function?: the function to apply to pairs of values
      (defaults to <append>)
    unit?: the value to return for an empty list

  Results:
    value: the reduced result

  The reduction order is not guaranteed, so the combine function must be
associative. A single-element list returns that element directly. The unit
value is only consumed when the list is empty.

  Topic: Lists

  See also: std_types::generic_list/std::map,
            std_types::generic_list/std::map_reduce

  Example:

    $scores list(85 92 78 95 88)
    $total reduce(scores plus)
    println! "total score: " total

  Output:

    total score: 438
