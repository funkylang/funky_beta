# std_types::generic_list/std::map_reduce_columns (a method)

  maps the elements of each row, then reduces them to one value

  Parameters:
    self: a list of lists
    map_function: a function applied to every element
    reduce_function: a function that combines two values into one

  Result:
    a list with one entry per row (a column vector)

  Each row is reduced to a single value. The map function first
  transforms every element of the row, then the reduce function
  combines the transformed values into one. The result has the same
  length as the input: its i-th entry is the reduced value of the
  i-th row. No intermediate list of mapped values is created.

  Topic: Lists

  See also: std_types::generic_list/std::map,
            std_types::generic_list/std::reduce

  Example:

    $rows list(list(1 2 3) list(4 5 6))
    map_reduce_columns $totals
      rows
      : (x)
        -> x*2
      : (a b)
        -> a+b
    dump! `totals

  Output:

    totals: list <2>
      12
      30
