# std_types::generic_list/std::map_reduce_columns (a method)

  maps every element and combines the results into one value per column

  Parameters:
    self: a list of lists
    map_function: a function applied to every element
    reduce_function: a function that combines two values into one

  Result:
    a list with one entry per column position

  The map function first transforms every element, then the reduce
  function combines the transformed values at each column position across
  all rows. The result has one entry per column position: its i-th entry
  is the reduced value of the elements at position i of every row. No
  intermediate list of mapped values is created.

  The reduction order is not guaranteed, so the reduce function must
  be associative.

  Topic: Lists

  See also: std_types::generic_list/std::map,
            std_types::generic_list/std::reduce

  Example:

    $print_list: (items)

            i == 1
            : print! items(i)
            : print! " " items(i)
          next!
        pass
      println!

    $print_list_of_lists: (grid)
      for_each! grid
        : (row)
          print_list! row
          next!
        pass
