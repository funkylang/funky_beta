# std_types::generic_list/std::common_prefix (a method)

  computes the common prefix of two lists

  Parameters:
    left: the first list
    right: the second list

  Result:
    list: the common prefix of the two lists

  The common prefix of two lists is the longest list that is a prefix of
  both lists.

  Topic: Lists

  See also: std_types::generic_list/std::intersection

  Example:

    $letters_a list("a" "b" "c")
    $letters_b list("a" "b" "z")
    $prefix common_prefix(letters_a letters_b)
    debug::dump 99 `prefix
    $cities_a list("Berlin" "Hamburg" "Munich")
    $cities_b list("Bonn" "Berlin" "Muenster")
    $no_common common_prefix(cities_a cities_b)
    if no_common.is_not_empty
      :
        println! "cities share: @(no_common(1))"
      :
        println! "the city lists have no common prefix"

  Output:

    the city lists have no common prefix

  Error output:

    prefix:
      list
        "a"
        "b"
