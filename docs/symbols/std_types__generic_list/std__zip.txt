# std_types::generic_list/std::zip (a method)

  zip (merge) two collections

  All odd numbered items are taken from the first collection; all even
  numbered items from the second collection.

  If a collection runs out of items the remaining items of the other
  collection are simply appended.

  Parameters:
    left: the first list
    right: the second list

  Result:
    list: the zipped list

  Topic: Lists

  See also: std_types::generic_list/std::intersection,
            std_types::generic_list/std::merge

  Example:

    $keys list("name" "age" "city")
    $values list("Peter" 42 "Berlin")
    $pairs zip(keys values)
    debug::dump 99 `pairs

  Error output:

    pairs:
      list
        "name"
        "Peter"
        "age"
        42
        "city"
        "Berlin"
