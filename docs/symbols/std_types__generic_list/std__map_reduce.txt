# std_types::generic_list/std::map_reduce (a method)

  combines map and reduce into a single pass over a list

  Parameters:
    self: the list to work on
    map_function: a function that transforms each element
    reduce_function?: a two-argument combine function (defaults to <append>)
    unit?: the value to return for an empty list

  Results:
    result: the reduced result after mapping

  Unlike calling map followed by reduce, no intermediate list is created.
The map callback may accept one argument (the element value) or two arguments
(index and value). The reduction order is not guaranteed, so the combine
function must be associative. A single-element list returns the mapped value
directly. The unit value is only consumed when the list is empty.

  Topic: Lists

  See also: std_types::generic_list/std::map,
            std_types::generic_list/std::reduce

  Example:

    $items list(3 4 5)

    $square: (v)
      -> v*v

    $total map_reduce(items square plus)
    println! "sum of squares: " total

  Output:

    sum of squares: 50
