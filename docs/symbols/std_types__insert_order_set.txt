# std_types::insert_order_set (a type derived from std_types::set)

  a set whose items are stored in insertion order

  All items stored in the set must support the following methods:

  * <equal>

  Items are maintained in the order in which they were inserted,
  so iteration yields the keys from oldest to newest.

  Topics: Sets, Collections

            std_types::key_order_set, std_types::insert_order_table
