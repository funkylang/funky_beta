# std::drop (a polymorphic function)

  removes the last item of a collection without returning it

  Parameter:
    collection: the collection to modify

  Result:
    collection: the collection with the last item removed

  Returns the modified collection but discards the removed item. Use when
  you only need to shorten the collection and don't care about what was
  removed.

  Topic: Collections

  See also: std::pop, std::peek, std::push, std::put

  Example:

    $items list(1 2 3 4 5)
    $shorter drop(items)
    debug::dump 99 `shorter

  Output:

    shorter:
      list
        1
        2
        3
        4
