# std_types::octet_string/: (a type function)

  get or set an octet string character by index

  Parameter:
    self: the octet string

  Results:
    character: the character at the given index (one-based)

  Called with one argument returns the character at that position. Called
  with two arguments returns a new octet string with the character at the
  first argument replaced by the second. Replacing with a 32-bit character
  produces a <std_types::wide_string>.

  Topic: Strings

  See also: std_types::octet_string, std::get, std::put

  Topic: Arrays

  Example:

    $s "abc"
    dump! `s(1) `s(-1)

  Output:

    s(1): 'a'
    s(-1): 'c'
