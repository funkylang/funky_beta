# std::access_time_of (a polymorphic function)

  returns the access time of a file

  Parameter:
    self: the file

  Result:
    time: the access time as a date_and_time object

  Returns the last access time of a file as a <std_types::date_and_time>
  object. The access time reflects the most recent point at which the file was
  read or otherwise accessed.

  Topic: Input-Output

  See also: std::modification_time_of, std::status_change_time_of,

  Example:
