# std::to_hash_bag (a polymorphic function)

  converts a collection into a hash bag

  Parameters:
    collection: the collection to convert

  Result:
    the converted hash bag

  Currently only <std_types::list> implements this function. The list
  must contain key-value pairs; each pair contributes its value as the
  count stored for its key in the new bag. If a key appears more than
  once, the last pair wins and earlier counts are discarded. The input
  list is not changed.

  Topic: Bags

  See also: std_types::hash_bag, std::empty_hash_bag, std::hash_bag,
            std_types::list/std::to_hash_bag

  Example:

    $pairs list("apple" = 2 "pear" = 1 "banana" = 3)
    $basket to_hash_bag(pairs)
    println! "apple: @(basket("apple"))"
    println! "items: @(length_of(basket))"
    debug::dump 99 `basket

  Output:

    apple: 2
    items: 3

  Error output:

    basket:
      hash_bag
        "pear" = 1
        "apple" = 2
        "banana" = 3
