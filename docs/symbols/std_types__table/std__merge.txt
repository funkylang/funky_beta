# std_types::table/std::merge (a method)

  merges another table into self, with an optional conflict function

  Parameters:
    self: the base table
    other: the table whose entries are merged into self
    merge_function?: called when both tables share a key

  Results:
    a cloned table with the merged entries

  Merges all key-value pairs from <other> into <self>. For keys that
  exist in only one table, the value is copied over. When both tables
  share a key, the value from <other> wins — unless a <merge_function>
  is provided. In that case, the merge function receives the value from
  <self> and the value from <other> and returns the combined result.
  Returns a cloned table; the original tables remain unchanged.

  Topic: Collections

  See also: std::add, std::difference

  Example:

    $base
      hash_table
        "alpha" = 10
        "beta" = 20

    $extra
      hash_table
        "beta" = 30
        "gamma" = 40

    merge $merged base extra
    debug::dump 99 `merged

  Output:

    merged:
      hash_table
        "beta" = 30
        "gamma" = 40
        "alpha" = 10

  Example:

    $table_1
      hash_table
        "x" = 1
        "y" = 2

    $table_2
      hash_table
        "y" = 3
        "z" = 4

    merge $combined table_1 table_2: (old_val new_val)
      -> old_val+new_val
    debug::dump 99 `combined

  Output:

    combined:
      hash_table
        "y" = 5
        "x" = 1
        "z" = 4
