# std_types::table/std::deserializer_of (a method)

  returns a function that reconstructs a table from its serialized form

  Parameters:
    type: the type of the table
    items: the deserialized items, alternating keys and values

  Result:
    table: the deserialized table

  The returned function is used by std::deserialize to rebuild a table
  during deserialization. It creates an empty table of the given type
  and fills it with the key-value pairs found in the serialized text.
  Because nested tables are deserialized before their parent, every
  item has already been turned into a real object by the time the
  function is called, so it simply stores the pairs as they are.

  Topics: Tables, Serialization

  See also: std_types::table/std::serialize, std::deserialize,
            std_types::table/std::to_list

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/insert_order_table>

    $scores insert_order_table("math" = 90 "physics" = 78)
    $text serialize(scores)
    $back deserialize(text)
    for_each! back
      : (subject score)
        println! subject ": " score
        next!
      pass

  Output:

    math: 90
    physics: 78
