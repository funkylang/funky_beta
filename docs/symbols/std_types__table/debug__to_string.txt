# std_types::table/debug::to_string (a method)

  creates a string representation of the table

  Parameters:
    self: the table to convert
    indent?: the number of spaces used for indentation
    depth?: the maximum recursion depth

  Result:
    string: the string representation of the table

  The string representation always ends with a line feed. At the default
  depth of 1 it is a single line; only increasing the depth reveals each
  key-value pair on its own line, indented according to the indentation
  level, with nested values revealed one level deeper than their keys.

  An empty table is abbreviated as "empty_" followed by its serialization
  tag, e.g. "empty_..._table". A non-empty table at depth 1 is abbreviated
  using the same tag, e.g. "\<..._table with N items>", without showing
  its contents.

  This function can be called without I/O-access rights.

  Topic: Tables

  See also: debug::to_string, std_types::table/std::serialize

  Example:

    $empty empty_hash_table
    $settings insert_order_table("name" = "Ada" "age" = 36 "role" = 7)
    println! debug::to_string(empty)
    println! debug::to_string(settings)
    println! debug::to_string(settings 0 99)

  Output:

    empty_hash_table

    <insert_order_table with 3 items>

    insert_order_table
      "name" = "Ada"
      "age" = 36
      "role" = 7
