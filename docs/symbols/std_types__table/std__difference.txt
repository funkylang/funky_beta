# std_types::table/std::difference (a method)

  computes the difference between two tables using a function

  Parameters:
    self: the base table (modified in place)
    other: the table of entries to compare against
    difference_function: a function called for each shared key

  Results:
    the modified base table

  Compares <self> against <other>. For each key present in <other>,
  calls the <difference_function> with both the value from <self> and
  the value from <other>. The returned value replaces the value in
  <self>. Keys only in <self> remain unchanged. Keys only in <other>
  are ignored.

  Topic: Collections

  See also: std::add, std::merge

  Example:

    $prices1
      hash_table
        "apple" = 100
        "banana" = 50
        "cherry" = 75

    $prices2
      hash_table
        "apple" = 120
        "banana" = 55

    $diff_func: (v1 v2)
      -> v1-v2

    difference &prices1 prices2 diff_func
    debug::dump 99 `prices1

  Output:

    prices1:
      hash_table
        "apple" = -20
        "cherry" = 75
        "banana" = -5
