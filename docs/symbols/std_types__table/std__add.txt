# std_types::table/std::add (a method)

  adds key-value pairs to a table

  Parameters:
    self: the table to add pairs to
    pairs*: one or more key-value pairs

  Results:
    a new table with the added pairs

  Adds the given key-value pairs to the table. If a key
  already exists, its value is updated. Accepts any number
  of key-value pairs.

  Topic: Collections

  See also: std::difference, std::merge

  Example:

    $config
      hash_table
        "timeout" = 30
        "retries" = 3

    add &config
      "timeout" = 60
      "verbose" = true

    debug::dump 99 `config

  Output:

    config:
      hash_table
        "retries" = 3
        "verbose" = true
        "timeout" = 60
