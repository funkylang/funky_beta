# llama::text_of (a polymorphic function)

  the text carried by a llama-server completion metadata object

  Parameters:
    meta: a llama_types::metadata object from llama::complete

  Result:
    text: the generated text, or an empty string if not yet set

  Returns the text of this completion. While streaming, each READ event's
  metadata contains only the token text for that chunk. With ONE_SHOT or in
  non-streaming mode, this holds the complete generated response. The value is
  set automatically from the server's reply.

  Topic: AI

  See also: llama_types::metadata, llama::METADATA

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ What is the capital of France?"
      METADATA
      MAX_TOKENS = 20
      TEMPERATURE = 0.7

    println! "Text:@nl;" trim(llama::text_of(meta))

  Output:

    Text:
    The capital of France is Paris.

    <think>
    Thinking Process:

    1.  **An
