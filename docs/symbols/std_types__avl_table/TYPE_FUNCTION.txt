# std_types::avl_table/: (a type function)

  retrieve, insert, or delete a key-value pair from a self-balancing AVL tree

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    result: the stored value (retrieve) or modified table (insert/delete)

  Calling a <std_types::avl_table> with a single key retrieves the
  associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a clone of the table. Keys must support comparison via
  <less> and <equal> operators. Internally, the table uses a self-balancing
  AVL tree with single and double rotations to maintain height balance.
  Each node stores its height for efficient rebalancing.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a clone with length decreased by one. Attempting
  to delete a non-existent key returns an unchanged clone.

  Topic: Tables

  See also: std::empty_avl_table, std_types::avl_table

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/binary_table>
    <require basic/types/collections/tables/avl_table>

    $scores empty_avl_table
    !scores("math") 95
    !scores("english") 88
    !scores("science") 91
    println! scores("english")
    !scores("english") 92
    println! scores("english")

  Output:

    88
    92
