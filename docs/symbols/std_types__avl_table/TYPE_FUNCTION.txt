# std_types::avl_table/: (a type function)

  retrieve, insert, or delete a key-value pair from a self-balancing AVL tree

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    the stored value on retrieval, or the modified table on insert/delete

  Calling a <std_types::avl_table> with a single key retrieves the
  associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a cloned table with the new entry; the original table remains
  unchanged. Keys must support comparison via <less> and <equal>
  operators. The tree rebalances automatically via rotations so that
  the height of any subtree differs from its sibling by at most one.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a cloned table with the entry removed; the original
  table remains unchanged. Attempting to delete a non-existent key
  returns the original table unchanged.

  Topic: Tables

  See also: std::empty_avl_table, std_types::binary_table, std_types::lb2_table

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/binary_table>
    <require basic/types/collections/tables/avl_table>

    $scores empty_avl_table
    !scores("math") 95
    !scores("english") 88
    !scores("science") 91
    println! scores("english")
    !scores("english") 92
    println! scores("english")

  Output:

    88
    92
