# std_types::table (a type derived from std_types::collection)

  the prototype object for all kinds of tables

  A table is a key-value store in which keys are associated with
  values. Each entry consists of a key and a value; keys must be
  unique within a table, so a key always determines at most one
  entry. An entry can be retrieved by calling the table with the key,
  which returns the associated value or <undefined> if the key is not
  present. Modifications return a cloned table; the original table
  remains unchanged.

  Concrete table types differ in how their entries are stored and
  ordered. All derived types inherit the methods defined for this
  type: add, merge, difference, to_list, serialize and
  deserializer_of.

  Topics: Tables, Collections

  See also: std_types::hash_table, std_types::key_order_table,
            std_types::association_list

  Example:

    $ages empty_hash_table
    !ages("Alice") 30
    !ages("Bob") 25
    add &ages "Carol" = 28
    println! ages("Alice")
    !ages("Alice") 31
    println! ages("Alice")
    !ages("Bob") undefined
    println! length_of(ages)

  Output:

    30
    31
    2
