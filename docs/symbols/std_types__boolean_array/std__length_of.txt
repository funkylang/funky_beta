# std_types::boolean_array/std::length_of (a method)

  returns the length of a dimension in a boolean array

  Parameters:
    array: a boolean array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::boolean_array/std::dimension_count_of

  Example:

    $flags boolean_array(5)
    !flags(1) std::true
    !flags(2) std::false
    !flags(3) std::true
    !flags(4) std::true
    !flags(5) std::false

    $len length_of(flags)
    println! "flag count: " len

    $grid boolean_array(2 3)
    println! "rows: " length_of(grid 1)
    println! "columns: " length_of(grid 2)

  Output:

    flag count: 5
    rows: 2
    columns: 3
