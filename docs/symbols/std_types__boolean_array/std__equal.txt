# std_types::boolean_array/std::equal (a method)

  compares two boolean arrays element by element

  Parameters:
    left: a boolean array
    right: a boolean array

  Result:
    true if both arrays have the same shape and identical elements,
    false otherwise

  Two arrays are equal when they have matching dimensions and every
corresponding element holds the same value. Arrays with different
shapes always compare as unequal.

  Topic: Arrays

  See also: std::equal

  Example:

    $flags_a boolean_array(2 3)
    !flags_a(1 1) std::true
    !flags_a(1 2) std::false
    !flags_a(1 3) std::true
    !flags_a(2 1) std::false
    !flags_a(2 2) std::true
    !flags_a(2 3) std::false

    $flags_b boolean_array(2 3)
    !flags_b(1 1) std::true
    !flags_b(1 2) std::false
    !flags_b(1 3) std::true
    !flags_b(2 1) std::false
    !flags_b(2 2) std::true
    !flags_b(2 3) std::false

    $flags_c boolean_array(2 3)
    !flags_c(1 1) std::true
    !flags_c(1 2) std::false
    !flags_c(1 3) std::true
    !flags_c(2 1) std::false
    !flags_c(2 2) std::false
    !flags_c(2 3) std::false
