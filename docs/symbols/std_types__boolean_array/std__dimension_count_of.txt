# std_types::boolean_array/std::dimension_count_of (a method)

  returns the number of dimensions of a boolean array

  Parameter:
    array: a boolean array

  Result:
    the number of dimensions as an integer

  A one-dimensional array returns 1, a two-dimensional array returns 2, etc.

  Topic: Arrays

  See also: std::dimension_count_of, std_types::boolean_array/std::length_of

  Example:

    $flags boolean_array(4)
    !flags(1) std::true
    !flags(2) std::false
    !flags(3) std::true
    !flags(4) std::false

    println! "dimensions: " dimension_count_of(flags)

    $grid boolean_array(2 3)
