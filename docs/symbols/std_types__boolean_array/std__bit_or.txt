# std_types::boolean_array/std::bit_or (a method)

  performs an element-wise logical OR on two boolean arrays

  Parameters:
    left: a boolean array
    right: a boolean array of the same shape

  Result:
    a new array with each element being the logical OR of the corresponding
    elements in the two input arrays

  Both operands must have identical dimensions. The result is a new array; the
originals remain unchanged. If both operands are the same object, returns
that object unchanged.

  Topic: Arrays

  See also: std::bit_or, std_types::boolean_array/std::bit_and,
            std_types::boolean_array/std::bit_xor

  Example:

    $print_bools: (data)
      $row_count length_of(data 1)
      $column_count length_of(data 2)
      from_to 1 row_count
        : (row_no)
          from_to 1 column_count
            : (col_no)
              if
                data(row_no col_no)
                : print! "true  "
                : print! "false "
              next!
          println!
          next!
        pass

    $flags_a boolean_array(2 3)
    !flags_a(1 1) std::true
    !flags_a(1 2) std::true
    !flags_a(1 3) std::false
    !flags_a(2 1) std::false
    !flags_a(2 2) std::true

    println! "A:"
