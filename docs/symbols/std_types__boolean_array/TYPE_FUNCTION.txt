# std_types::boolean_array/: (a type function)

  gets or sets an element in a boolean array

Calling a <std_types::boolean_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are true or false.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged.

  Topic: Arrays

  See also: std_types::boolean_array, std::empty_boolean_array

  Example:

    $flags boolean_array(4)
    !flags(1) std::true
    !flags(2) std::false
    if
      flags(1)
      :
        println! "First flag is true"
      :
        println! "First flag is false"

  Output:

    First flag is true
