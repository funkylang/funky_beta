# std_types::boolean_array/std::range (a method)

  creates a new boolean array with the elements in the given range

  Parameters:
    array: a boolean array
    ranges?: one or more value ranges, one per dimension

  Result:
    a new boolean array containing the selected elements

  The range argument is a value_range (start..end, inclusive). Supply one
range per dimension for multi-dimensional arrays. Returns a cloned array;
the original remains unchanged.

  Topic: Arrays

  See also: std::range, std_types::boolean_array/std::length_of

  Example:

    $flags boolean_array(6)
    !flags(1) std::true
    !flags(2) std::false
    !flags(3) std::true
    !flags(4) std::false
    !flags(5) std::true
    !flags(6) std::true

    $subset range(flags 2..5)
    println! "length: " length_of(subset)
    if
      subset(1)
      : println! "first: true"
      : println! "first: false"
    if
      subset(4)
      : println! "last: true"
      : println! "last: false"

  Output:

    length: 4
    first: false
    last: true
