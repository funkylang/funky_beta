# llama::METADATA (a unique item)

  the metadata option for llama-server completion requests

  Use as a key in the options of <llama::complete> to request metadata objects
  instead of plain text. When present, the result becomes a
  <llama_types::metadata> object containing all server-reported fields: the
  generated text, token counts, finish reason, model name, and more. The text
  itself is then read through llama::text_of(meta). Since it defaults to false,
  specifying the option alone requests metadata.

  Topic: AI

  See also: llama::complete, llama_types::metadata

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ What color is the sky on a clear day?"
      METADATA
      MAX_TOKENS = 20
      TEMPERATURE = 0

    println! llama::text_of(meta)

  Output:

    <think>

    </think>

    On a clear day, the sky is typically **blue**.
