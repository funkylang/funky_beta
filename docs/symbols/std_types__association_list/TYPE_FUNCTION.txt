# std_types::association_list/: (a type function)

  retrieve, insert, or delete a key-value pair from an association list

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    result: the stored value (retrieve) or modified table (insert/delete)

  Calling a <std_types::association_list> with a single key retrieves
  the associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a clone of the table. Keys only need to support comparison
  via <equal> operators, unlike ordered table types which require
  <less>. Internally, entries are stored as a linked list of key-value
  pairs, making it the simplest table structure but slower for large
  datasets.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a clone with length decreased by one. Attempting
  to delete a non-existent key returns an unchanged clone.

  Topic: Tables

  See also: std::empty_association_list, std_types::association_list

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/association_list>

    $prefs empty_association_list
    !prefs("theme") "dark"
    !prefs("font") "monospace"
    println! prefs("theme")
    !prefs("theme") "light"
    println! prefs("theme")

  Output:

    dark
    light
