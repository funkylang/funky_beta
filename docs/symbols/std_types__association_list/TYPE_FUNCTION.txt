# std_types::association_list/: (a type function)

  retrieve, insert, or delete a key-value pair from an association list

  Parameters:
    key: the lookup key
    value?: new value to store (or undefined to delete)

  Result:
    the stored value on retrieval, or the modified table on insert/delete

  Calling a <std_types::association_list> with a single key retrieves
  the associated value, or <undefined> if the key is not present.

  With two arguments, it inserts or updates the key-value pair and
  returns a cloned table with the new entry; the original table remains
  unchanged. Keys only need to support comparison via <equal>, unlike
  ordered table types which require <less>.

  Passing <undefined> as the second argument deletes the key if it
  exists, returning a cloned table with the entry removed; the original
  table remains unchanged. Deleting a non-existent key returns the
  original table unchanged.

  Topic: Tables

  See also: std::empty_association_list, std_types::table

  Example:

    <require basic/stdlib>
    <require basic/types/collections/tables/association_list>

    $prefs empty_association_list
    !prefs("theme") "dark"
    !prefs("font") "monospace"
    println! prefs("theme")
    !prefs("theme") "light"
    println! prefs("theme")

  Output:

    dark
    light
