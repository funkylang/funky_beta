# std_types::association_list/std::map (a method)

  applies a function to all values of the association list

  Parameters:
    self: the association list whose values will be mapped
    function: the function to apply to each element

  Result:
    an association list containing the mapped items

  Returns a cloned association list with each value transformed by the
  function; the original list remains unchanged. The function is dispatched
  based on its parameter count.

  **Two parameters:** the function receives the key and the value for each
  item, allowing the transformation to depend on the key.

  **One parameter:** the function receives only the value; the key is not
  passed.

  The function applications may be executed in parallel. The callback is
  invoked without I/O-access rights.

  Topic: Tables

  See also: std_types::association_list/std::reduce,
            std_types::association_list/std::map_reduce

  Example:

    $ages empty_association_list
    !ages("John") 42
    !ages("Mary") 25
    !ages("Irene") 49

    $double: (v)
      times v 2

    map $result ages double

    for_each result
      : (name age)
        println! name ": " age
        next!
      pass

  Output:

    Irene: 98
    Mary: 50
    John: 84
