# std_types::uint64_array/: (a type function)

  gets or sets an element in a uint64 array

Calling a <std_types::uint64_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are unsigned 64-bit integers.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged. Values outside
  the range wrap using modulo arithmetic.

  Topic: Arrays

  See also: std_types::uint64_array, std::empty_uint64_array

  Example:

    $big_numbers uint64_array(4)
    !big_numbers(1) 9223372036854775807
    println! "First number: " big_numbers(1)

  Output:

    First number: 9223372036854775807
