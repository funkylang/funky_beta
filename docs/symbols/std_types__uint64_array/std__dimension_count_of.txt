# std_types::uint64_array/std::dimension_count_of (a method)

  returns the number of dimensions of an unsigned 64-bit array

  Parameter:
    array: an unsigned 64-bit array

  Result:
    the number of dimensions as an integer

  A one-dimensional array returns 1, a two-dimensional array returns 2, etc.

  Topic: Arrays

  See also: std::dimension_count_of, std_types::uint64_array/std::length_of

  Example:

    $counts uint64_array(3)
    !counts(1) 9007199254740992
    !counts(2) 4503599627370496
    !counts(3) 18014398509481984

    println! "dimensions: " dimension_count_of(counts)

    $grid uint64_array(4 4)
    println! "grid dimensions: " dimension_count_of(grid)

  Output:

    dimensions: 1
    grid dimensions: 2
