# std_types::uint64_array/std::bit_or (a method)

  performs an element-wise bitwise OR on two unsigned 64-bit arrays

  Parameters:
    left: an unsigned 64-bit array
    right: an unsigned 64-bit array of the same shape

  Result:
    a new array with each element being the bitwise OR of the corresponding
    elements in the two input arrays

  Both operands must have identical dimensions. The result is a new array; the
originals remain unchanged. If both operands are the same object, returns
that object unchanged.

  Topic: Arrays

  See also: std::bit_or, std_types::uint64_array/std::bit_and,
            std_types::uint64_array/std::bit_xor

        pass
