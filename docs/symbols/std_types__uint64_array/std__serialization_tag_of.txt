# std_types::uint64_array/std::serialization_tag_of (an attribute)

  the serialization identifier for unsigned 64-bit arrays

  Parameters:
    none

  Results:
    none

  Returns the string "uint64_array", which identifies this type during
serialization and deserialization. The tag is used internally by the
serialization framework to reconstruct the correct array type when
reading data back.

  Topic: Arrays

  See also: std::serialize, std::deserialize

  Example:

    $arr uint64_array(3)
    !arr(1) 9007199254740992
    !arr(2) 4503599627370496
    !arr(3) 18014398509481984

    println! "type tag: " serialization_tag_of(arr)
