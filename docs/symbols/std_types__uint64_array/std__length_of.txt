# std_types::uint64_array/std::length_of (a method)

  returns the length of a dimension in an unsigned 64-bit array

  Parameters:
    array: an unsigned 64-bit array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::uint64_array/std::dimension_count_of

  Example:

    $counts uint64_array(4)
    !counts(1) 9007199254740992
    !counts(2) 4503599627370496
    !counts(3) 18014398509481984
    !counts(4) 900719925474099

    $len length_of(counts)
    println! "count: " len

    $matrix uint64_array(2 3)
    println! "rows: " length_of(matrix 1)
    println! "columns: " length_of(matrix 2)

  Output:

    count: 4
    rows: 2
    columns: 3
