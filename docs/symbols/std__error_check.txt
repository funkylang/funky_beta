# std::error_check (a function)

raises an error if any of its arguments is an error object

  Parameter:
    args*: objects to check

  Result:
    nothing if none of the arguments is an error object

  When error objects are stored in variables or collections, the error may not
  propagate until the value is used. *error_check* re-raises the first error
  found among its arguments, making failures visible immediately.

  This function does not need I/O-access rights.

  Topic: Errors

  See also: std::try

  Example:

    load! $data_1 "non-existing-file"
    load! $data_2 "another-missing-file"
    error_check data_1 data_2
