# std_types::int32_array/: (a type function)

  gets or sets an element in an int32 array

Calling a <std_types::int32_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are 32-bit signed integers between -2147483648 and 2147483647.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged. Values outside
  the range wrap using modulo arithmetic.

  Topic: Arrays

  See also: std_types::int32_array, std::empty_int32_array

  Example:

    $scores int32_array(4)
    !scores(1) 9850
    !scores(2) -200
    println! "First score: " scores(1)

  Output:

    First score: 9850
