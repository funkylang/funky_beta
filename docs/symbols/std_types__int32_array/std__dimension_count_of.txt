# std_types::int32_array/std::dimension_count_of (a method)

  returns the number of dimensions of a signed 32-bit array

  Parameter:
    array: a signed 32-bit array

  Result:
    the number of dimensions as an integer

  A one-dimensional array returns 1, a two-dimensional array returns 2, and so
  on.

  Topic: Arrays

  See also: std::dimension_count_of, std_types::int32_array/std::length_of

  Example:

    $velocities int32_array(3)
    !velocities(1) 54000
    !velocities(2) -12000
    !velocities(3) 87000

    println! "dimensions: " dimension_count_of(velocities)

    $grid int32_array(4 4)
    println! "grid dimensions: " dimension_count_of(grid)

  Output:

    dimensions: 1
    grid dimensions: 2
