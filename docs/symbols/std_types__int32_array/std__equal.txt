# std_types::int32_array/std::equal (a method)

  compares two signed 32-bit arrays element by element

  Parameters:
    left: a signed 32-bit array
    right: a signed 32-bit array

  Result:
    true if both arrays have the same shape and identical elements,
    false otherwise

  Two arrays are equal when they have matching dimensions and every
corresponding element holds the same value. Arrays with different
shapes always compare as unequal.

  Topic: Arrays

  See also: std::equal, std_types::int32_array/std::less

  Example:

    $distances int32_array(3)
    !distances(1) 54000
    !distances(2) -12000
    !distances(3) 87000

    $distances_copy int32_array(3)
    !distances_copy(1) 54000
    !distances_copy(2) -12000
    !distances_copy(3) 87000

    $distances_other int32_array(3)
    !distances_other(1) 54000
    !distances_other(2) 0
    !distances_other(3) 87000

    if
      equal(distances distances_copy)
      : println! "copies match"
      : println! "copies differ"

    if
      equal(distances distances_other)
      : println! "originals match"
      : println! "originals differ"

  Output:

    copies match
    originals differ
