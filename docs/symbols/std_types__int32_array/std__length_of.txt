# std_types::int32_array/std::length_of (a method)

  returns the length of a dimension in a signed 32-bit array

  Parameters:
    array: a signed 32-bit array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::int32_array/std::dimension_count_of

  Example:

    $distances int32_array(4)
    !distances(1) 54000
    !distances(2) -12000
    !distances(3) 87000
    !distances(4) 23000

    $len length_of(distances)
    println! "distance count: " len

    $matrix int32_array(2 3)
    println! "rows: " length_of(matrix 1)
    println! "columns: " length_of(matrix 2)

  Output:

    distance count: 4
    rows: 2
    columns: 3
