# std_types::list/std::peek (a method)

  returns the last item of a non-empty list

  It is an error to attempt to peek an item of an empty list. The list
  itself remains unchanged.

  Parameters:
    self # the list

  Result:
    item # the last item of the list

  Topic: Lists

  See also: std::pop, std::drop, std::push, std::put

  Example:

    $agenda list("meeting" "review" "lunch")
    $last peek(agenda)
    println! "next up: @(last)"

  Output:

    next up: lunch
