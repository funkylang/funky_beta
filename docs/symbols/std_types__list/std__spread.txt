# std_types::list/std::spread (a method)

  returns the items of a list as separate results

  Parameters:
    self: the list

  Results:
    items*: the individual items of the list

  Returns every element of the list as a separate return value. A list with
  three items produces three results. The caller must declare the exact
  number of destinations, so this method is most useful when the list
  length is known.

  Topic: Lists

  See also: std_types::list/std::append, std::list

  Example:

    $items list(10 20 30)
    spread $a $b $c items
    println! "a=" a " b=" b " c=" c

  Output:

    a=10 b=20 c=30
