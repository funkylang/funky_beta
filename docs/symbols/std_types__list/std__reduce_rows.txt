# std_types::list/std::reduce_rows (a method)

  applies a reduction function pairwise to corresponding rows of two row-lists

  Parameters:
    self: the left list of lists
    reduction: a function that takes two items and returns a single value

  Result:
    a list containing the reduced rows

  Reduces a list of rows by applying the reduction function element-wise
  between adjacent rows. For each pair of corresponding elements, the
  reduction function receives the element from the left row and the
  matching element from the right row.

  Topic: Lists

  See also: std_types::list/std::reduce_columns, std_types::list/std::reduce
