# std_types::list/std::to_hash_bag (a method)

  converts a list of key-value pairs into a hash bag

  Parameters:
    items: a list containing tuples of KEY = value pairs

  Result:
    a hash bag with the extracted keys and values

  Iterates over the list, destructures each element into a key and value,
  then stores the pair in a newly created hash bag. Later pairs with the
  same key overwrite earlier ones.

  Topic: Tables

  See also: std::empty_hash_bag, std_types::hash_bag

  Example:

    $pairs list('a' = 1 'b' = 2 'c' = 3)
    $bag to_hash_bag(pairs)
    debug::dump 99 `bag

  Output:

    bag:
      hash_bag
        'c' = 3
        'b' = 2
        'a' = 1
