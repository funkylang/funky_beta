# std_types::list/std::deserializer_of (a method)

  returns a function that reconstructs a list from its serialized form

  Parameters:
    _type: the type of the collection
    items: the serialized items

  Result:
    list: the deserialized list

  The returned function is used by std::deserialize to rebuild a list
  during deserialization. It is called with the serialization tag and
  either a single serialized string (a flat list) or an integer that
  references one of the objects defined earlier in the serialized text
  (a nested list). The list's items have already been deserialized by
  then, so the function returns them unchanged.

  Topics: Lists, Serialization

  See also: std_types::list/std::serialize, std::deserialize,
            std_types::list/std::to_list

  Example:

    $scores list(72 45 88)
    $text serialize(scores)
    $back deserialize(text)
    dump! `back

  Output:

    back: list <3>
      72
      45
      88
