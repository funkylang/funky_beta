# std_types::list/std::pop (a method)

  removes and returns the last item of a non-empty list

  It is an error to attempt to pop an item from an empty list.

  The returned list maintains all attributes of the original list.

  Parameters:
    collection # the collection to be modified

  Results:
    collection # the modified collection
    item # the removed item

  Topic: Lists

  See also: std::peek, std::drop, std::push, std::put

  Example:

    $agenda list("meeting" "review" "lunch")
    pop !agenda $last agenda
    dump! `agenda
    println! "done: @(last)"

  Output:

    agenda: list <2>
      "meeting"
      "review"
    done: lunch
