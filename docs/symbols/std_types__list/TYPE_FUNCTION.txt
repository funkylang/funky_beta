# std_types::list/: (a type function)

access or replace an item at a given index

  Parameters:
    index: the 1-based position (negative values count from the end)
    item?: new value to place at the index

  Result:
    value: an item or a new list

  Calling a <std_types::list> with a single index returns the item
  at that position. Negative indices start from the end, where -1
  is the last item. This is the primary way to retrieve elements
  from a list.

  With two arguments, it returns a clone of the original list with
  the item at the given index replaced. The original list is
  unchanged, and all attributes of the list are preserved in the
  clone. The new item can be any type, even if it differs from the
  existing items.

  An index outside the range of the list, or an access on an empty
  list, raises an <std_types::error> with the message "INVALID
  INDEX". The error can be captured into a variable for safe
  handling without crashing.

  Topic: Collections

  See also: std::list

  Example:

    $items list(10 20 30)
    println! items(2)
    $new items(2 99)
    dump! `new
    $item items(77)
    dump! `item

  Output:

    20
    new: list <3>
      10
      99
      30
    item: INVALID INDEX
