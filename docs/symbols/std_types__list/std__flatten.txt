# std_types::list/std::flatten (a method)

  flattens all nested lists recursively into a single flat list

  Parameters:
    self: the list to flatten

  Result:
    a flat list

  Walks every element. Sub-lists are recursively flattened. Non-list items
  pass through unchanged.

  Topic: Lists

  See also: std_types::generic_list/std::flatten, std_types::list/std::append

  Example:

    $nested list(list(1 2) 3 list(4 list(5)))
    debug::dump 99 `flatten(nested)

  Output:

    flatten(nested):
      list
        1
        2
        3
        4
        5
