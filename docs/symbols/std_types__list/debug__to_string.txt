# std_types::list/debug::to_string (a method)

  creates a string representation of the list

  Parameters:
    self: the list to convert
    indent?: the indentation level
    depth?: the maximum depth

  Result:
    string: the string representation of the list

  The string representation is a multi-line string. At the default depth
  of 1, a non-empty list is abbreviated as "<list of N items>" without
  showing its contents. Increasing the depth reveals the list's items,
  indented according to the indentation level.

  Topic: Lists

  See also: std_types::list/std::serialize

  Example:

    $scores list(72 45 88)
    $text debug::to_string(scores)
    println! text
    $deep debug::to_string(scores 0 99)
    println! deep

  Output:

    <list of 3 items>
    
    list
      72
      45
      88
