# std_types::list/std::drop (a method)

  removes the last item of a non-empty list

  It is an error to attempt to drop an item from an empty list. The
  original list remains unchanged; all its attributes are maintained on
  the returned list.

  Parameters:
    collection # the collection to be modified

  Result:
    collection # the modified collection

  Topic: Lists

  See also: std::pop, std::peek, std::push, std::put

  Example:

    $agenda list("meeting" "review" "lunch")
    $shortened drop(agenda)
    dump! `shortened

  Output:

    shortened: list <2>
      "meeting"
      "review"
