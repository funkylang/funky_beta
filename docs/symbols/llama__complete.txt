# llama::complete (a polymorphic function)

  completes a prompt using a llama-server

  Parameters:
    see the implementations

  Result:
    see the implementations

  Completes a text prompt against a llama-server running on a host.
  Which call form you use depends on the type of the argument you pass
  first -- the function behaves differently for each one:

  **string** -- blocking: sends the prompt, waits for the complete
  response, and returns it. The result is the generated text as a string,
  or a <llama_types::metadata> object when the METADATA option (or LOGITS)
  is set. This form opens a TCP socket itself.

  **io object** -- non-blocking: merely schedules the request on the io
  object and returns it immediately. The answer arrives later as standard
  io events, identified by the stream identifier you chose.

  Both forms accept the same key-value options to configure host, port,
  model, sampling parameters, stop sequences, and result format; see the
  implementation pages for the full list with examples of every option.

  Topic: AI

  See also: llama_types::metadata

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $answer "What is the result of 7 times 8?"
      MAX_TOKENS = 5
      TEMPERATURE = 0

    println! answer
