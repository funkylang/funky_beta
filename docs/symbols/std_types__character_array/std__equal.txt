# std_types::character_array/std::equal (a method)

  compares two character arrays element by element

  Parameters:
    left: a character array
    right: a character array

  Result:
    true if both arrays have the same shape and identical elements,
    false otherwise

  Two arrays are equal when they have matching dimensions and every
corresponding element holds the same character. Arrays with different
shapes always compare as unequal.

  Topic: Arrays

  See also: std::equal

  Example:

    $letters_a character_array(3)
    !letters_a(1) 'a'
    !letters_a(2) 'b'
    !letters_a(3) 'c'

    $letters_b character_array(3)
    !letters_b(1) 'a'
    !letters_b(2) 'b'
    !letters_b(3) 'c'

    $letters_c character_array(3)
    !letters_c(1) 'a'
    !letters_c(2) 'x'
    !letters_c(3) 'c'

    if
      equal(letters_a letters_b)
      : println! "A and B are identical"
      : println! "A and B differ"

    if
      equal(letters_a letters_c)
      : println! "A and C are identical"
      : println! "A and C differ"

  Output:

    A and B are identical
    A and C differ
