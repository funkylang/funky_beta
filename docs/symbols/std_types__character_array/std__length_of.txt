# std_types::character_array/std::length_of (a method)

  returns the length of a dimension in a character array

  Parameters:
    array: a character array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::character_array/std::dimension_count_of

  Example:

    $chars character_array(5)
    !chars(1) 'H'
    !chars(2) 'e'
    !chars(3) 'l'
    !chars(4) 'l'
    !chars(5) 'o'

    $len length_of(chars)
    println! "character count: " len

    $grid character_array(2 3)
    println! "rows: " length_of(grid 1)
    println! "columns: " length_of(grid 2)

  Output:

    character count: 5
    rows: 2
    columns: 3
