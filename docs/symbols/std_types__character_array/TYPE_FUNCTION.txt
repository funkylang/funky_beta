# std_types::character_array/: (a type function)

  gets or sets an element in a character array

Calling a <std_types::character_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the character at that position (one-based).
  Characters are 32-bit unsigned Unicode codepoints.

  **Two arguments:** returns a cloned array with the character at that
  position set to the new value; the original array remains unchanged.

  Topic: Arrays

  See also: std_types::character_array, std::empty_character_array

  Example:

    $chars character_array(4)
    !chars(1) 'H'
    !chars(2) 'i'
    println! "First char: " chars(1)

  Output:

    First char: H
