# std_types::character_array/std::dimension_count_of (a method)

  returns the number of dimensions of a character array

  Parameter:
    array: a character array

  Result:
    the number of dimensions as an integer

  A one-dimensional array returns 1, a two-dimensional array returns 2, etc.

  Topic: Arrays

  See also: std::dimension_count_of, std_types::character_array/std::length_of

  Example:

    $chars character_array(4)
    !chars(1) 'H'
    !chars(2) 'e'
    !chars(3) 'l'
    !chars(4) 'o'

    println! "dimensions: " dimension_count_of(chars)

    $grid character_array(2 3)
