# std_types::character_array/std::range (a method)

  creates a new character array with the elements in the given range

  Parameters:
    array: a character array
    ranges?: one or more value ranges, one per dimension

  Result:
    a new character array containing the selected elements

  The range argument is a value_range (start..end, inclusive). Supply one
range per dimension for multi-dimensional arrays. Returns a cloned array;
the original remains unchanged.

  Topic: Arrays

  See also: std::range, std_types::character_array/std::length_of

  Example:

    $chars character_array(6)
    !chars(1) 'H'
    !chars(2) 'e'
    !chars(3) 'l'
    !chars(4) 'l'
    !chars(5) 'o'
    !chars(6) '!'

    $subset range(chars 1..4)
    print! "subset: "
    from_to 1 length_of(subset)
      : (i)
        print! subset(i)
        next!
    println!

  Output:

    subset: Hell
