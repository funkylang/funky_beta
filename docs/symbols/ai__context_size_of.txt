# ai::context_size_of (a polymorphic function)

  returns the trained context size of an AI model

  Returns the maximum context size the AI model was trained for. This is the
  upper limit for how many tokens the model can process at once. The effective
  context size set via <ai::effective_context_size_of> must be less than or
  equal to this value. A larger context size allows the model to consider more
  previous tokens, but also increases memory usage and processing time.

  Parameter:
    self: the AI model object

  Result:
    result: the trained context size as a number

  Topic: Deprecated AI

  See also: ai::effective_context_size_of, ai::load_ai_model

  Example:

    $model ai::load_ai_model(ai::SERVER_ADDRESS = "127.0.0.1")
    println! context_size_of(model)
