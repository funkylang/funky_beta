# std::is_an_octet_string (a polymorphic function)

  tests if an object is an octet string

  An octet string is a string where all characters fit into a single byte
  (values 0-255). This function returns true for octet string objects and
  false for regular strings or other types. It is useful for checking whether
  a string can be safely passed to functions that expect byte-level data.

  Parameter:
    self: the object to test

  Result:
    true if the object is an octet string, false otherwise
