# std_types::uint32_array/std::length_of (a method)

  returns the length of a dimension in an unsigned 32-bit array

  Parameters:
    array: an unsigned 32-bit array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::uint32_array/std::dimension_count_of

  Example:

    $scores uint32_array(5)
    !scores(1) 100
    !scores(2) 200
    !scores(3) 300
    !scores(4) 400
    !scores(5) 500

    $len length_of(scores)
    println! "score count: " len

    $grid uint32_array(2 3)
    println! "rows: " length_of(grid 1)
    println! "columns: " length_of(grid 2)

  Output:

    score count: 5
    rows: 2
    columns: 3
