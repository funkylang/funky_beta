# std_types::uint32_array/std::bit_xor (a method)

  performs an element-wise bitwise XOR on two unsigned 32-bit arrays

  Parameters:
    left: an unsigned 32-bit array
    right: an unsigned 32-bit array of the same shape

  Result:
    a new array with each element being the bitwise XOR of the
    corresponding elements in the two input arrays

  Both operands must have identical dimensions. The result is a new array; the
originals remain unchanged.

  Topic: Arrays

  See also: std::bit_xor, std_types::uint32_array/std::bit_and,
            std_types::uint32_array/std::bit_or
