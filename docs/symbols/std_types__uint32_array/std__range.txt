# std_types::uint32_array/std::range (a method)

  creates a new unsigned 32-bit array with the elements in the given range

  Parameters:
    array: an unsigned 32-bit array
    ranges?: one or more value ranges, one per dimension

  Result:
    a new unsigned 32-bit array containing the selected elements

  The range argument is a value_range (start..end, inclusive). Supply one
range per dimension for multi-dimensional arrays. Returns a cloned array;
the original remains unchanged.

  Topic: Arrays

  See also: std::range, std_types::uint32_array/std::length_of

  Example:
