# std_types::uint32_array/: (a type function)

  gets or sets an element in a uint32 array

Calling a <std_types::uint32_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are unsigned 32-bit integers.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged. Values outside
  the range wrap using modulo arithmetic.

  Topic: Arrays

  See also: std_types::uint32_array, std::empty_uint32_array

  Example:

    $pixel_counts uint32_array(4)
    !pixel_counts(1) 1048576
    !pixel_counts(2) 524288
    println! "First count: " pixel_counts(1)

  Output:

    First count: 1048576
