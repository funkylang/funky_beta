# std_types::uint32_array/std::dimension_count_of (a method)

  returns the number of dimensions of an unsigned 32-bit array

  Parameter:
    array: an unsigned 32-bit array

  Result:
    the number of dimensions as an integer

  A one-dimensional array returns 1, a two-dimensional array returns 2, etc.

  Topic: Arrays

  See also: std::dimension_count_of, std_types::uint32_array/std::length_of

  Example:

    $scores uint32_array(5)
    !scores(1) 100
    !scores(2) 200
    !scores(3) 300
    !scores(4) 400
    !scores(5) 500

    println! "dimensions: " dimension_count_of(scores)

    $grid uint32_array(4 4)
    println! "grid dimensions: " dimension_count_of(grid)

  Output:

    dimensions: 1
    grid dimensions: 2
