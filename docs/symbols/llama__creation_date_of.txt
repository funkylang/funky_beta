# llama::creation_date_of (a polymorphic function)

  the timestamp of when the server created a completion

  Parameters:
    meta: a llama_types::metadata object from llama::complete

  Result:
    date_time: a date_and_time object, or undefined if not yet reported

  When the server created this completion. The type is date_and_time, which
  can be formatted, compared, or used to calculate durations. Useful for
  latency checks (creation time minus request time) or auditing completion
  history.

  Topic: AI

  See also: llama_types::metadata

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Hi"
      METADATA
      MAX_TOKENS = 3
      TEMPERATURE = 0

    println! "Created at: " debug::to_string(creation_date_of(meta) 0 1)

  Output:

    Created at: <date and time 1789641881.000000000>
