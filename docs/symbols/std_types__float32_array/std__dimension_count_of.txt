# std_types::float32_array/std::dimension_count_of (a method)

  returns the number of dimensions of a single-precision floating-point array

  Parameter:
    array: a float32 array

  Result:
    the number of dimensions as an integer

  A one-dimensional array returns 1, a two-dimensional array returns 2, etc.

  Topic: Arrays

  See also: std::dimension_count_of, std_types::float32_array/std::length_of

  Example:

    $temps float32_array(4)
    !temps(1) 22.5
    !temps(2) 19.8
    !temps(3) 24.1
    !temps(4) 21.3

    println! "dimensions: " dimension_count_of(temps)

    $grid float32_array(2 3)
    println! "grid dimensions: " dimension_count_of(grid)

  Output:

    dimensions: 1
    grid dimensions: 2
