# std_types::uint16_array/std::bit_xor (a method)

  performs an element-wise bitwise XOR on two unsigned 16-bit arrays

  Parameters:
    left: an unsigned 16-bit array
    right: an unsigned 16-bit array of the same shape

  Result:
    a new array with each element being the bitwise XOR of the
    corresponding elements in the two input arrays

  Both operands must have identical dimensions. The result is a new array; the
originals remain unchanged.

  Topic: Arrays

  See also: std::bit_xor, std_types::uint16_array/std::bit_and,
            std_types::uint16_array/std::bit_or

  Example:

    $print_hex: (data)
      $row_count length_of(data 1)
      $column_count length_of(data 2)
      from_to 1 row_count
        : (row_no)
          from_to 1 column_count
            : (col_no)
              $val data(row_no col_no)
              print! hex(val 4) " "
              next!
          println!
          next!
        pass

    $mask_a uint16_array(2 3)
    !mask_a(1 1) 15
    !mask_a(1 2) 60
    !mask_a(1 3) 255
    !mask_a(2 1) 170
    !mask_a(2 2) 85
    !mask_a(2 3) 42

    $mask_b uint16_array(2 3)
    !mask_b(1 1) 9
    !mask_b(1 2) 30
    !mask_b(1 3) 0
    !mask_b(2 1) 85
    !mask_b(2 2) 170
    !mask_b(2 3) 42

    println! "A:"
    print_hex! mask_a
    println! ""
    println! "B:"
    print_hex! mask_b
    println! ""
    $result mask_a .bit_xor. mask_b
    println! "A ^ B:"
    print_hex! result
