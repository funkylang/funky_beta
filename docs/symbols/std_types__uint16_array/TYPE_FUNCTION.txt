# std_types::uint16_array/: (a type function)

  gets or sets an element in a uint16 array

Calling a <std_types::uint16_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are unsigned 16-bit integers between 0 and 65535.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged. Values outside
  the range wrap using modulo arithmetic.

  Topic: Arrays

  See also: std_types::uint16_array, std::empty_uint16_array

  Example:

    $ports uint16_array(4)
    !ports(1) 8080
    !ports(2) 3000
    println! "First port: " ports(1)

  Output:

    First port: 8080
