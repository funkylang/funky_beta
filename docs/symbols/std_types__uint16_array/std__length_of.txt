# std_types::uint16_array/std::length_of (a method)

  returns the length of a dimension in an unsigned 16-bit array

  Parameters:
    array: an unsigned 16-bit array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::uint16_array/std::dimension_count_of

  Example:

    $pressures uint16_array(4)
    !pressures(1) 1024
    !pressures(2) 512
    !pressures(3) 2048
    !pressures(4) 768

    $len length_of(pressures)
    println! "pressure count: " len

    $matrix uint16_array(2 3)
    println! "rows: " length_of(matrix 1)
    println! "columns: " length_of(matrix 2)

  Output:

    pressure count: 4
    rows: 2
    columns: 3
