# std_types::uint16_array/std::equal (a method)

  compares two unsigned 16-bit arrays element by element

  Parameters:
    left: an unsigned 16-bit array
    right: an unsigned 16-bit array

  Result:
    true if both arrays have the same shape and identical elements,
    false otherwise

  Two arrays are equal when they have matching dimensions and every
corresponding element holds the same value. Arrays with different
shapes always compare as unequal.

  Topic: Arrays

  See also: std::equal, std_types::uint16_array/std::less

  Example:
