# std_types::uint16_array/std::bit_and (a method)

  performs an element-wise bitwise AND on two unsigned 16-bit arrays

  Parameters:
    left: an unsigned 16-bit array
    right: an unsigned 16-bit array of the same shape

  Result:
    a new array with each element being the bitwise AND of the
    corresponding elements in the two input arrays

  Both operands must have identical dimensions. The result is a new array; the
originals remain unchanged. If both operands are the same object, returns
that object unchanged.

  Topic: Arrays

  See also: std::bit_and, std_types::uint16_array/std::bit_or,
            std_types::uint16_array/std::bit_xor

  Example:

    $print_array: (data)
      $row_count length_of(data 1)
      $column_count length_of(data 2)
      $separator_line append("+" dup("--------+" column_count))
      println! separator_line
      from_to 1 row_count
        : (row_no)
          print! "|"
          from_to 1 column_count

              $val data(row_no col_no)
              print! " " hex(val 4) "   |"
              next!
          println!
          println! separator_line
          next!
        pass
