# std_types::generic_array/std::map_reduce (a method)

  combines map and reduce into a single pass over an array

  Parameters:
    self: the array to work on
    map_function: a function that transforms each element
    reduce_function?: a two-argument combine function (defaults to <append>)
    unit?: an initial value for empty arrays

  Results:
    result: the reduced result after mapping

  Unlike calling map followed by reduce, no intermediate array is created.
The reduce function must be associative. For non-empty arrays there is no
guaranteed order in which reductions take place — any element can serve as
the starting point and a single-element array returns that element directly.
The unit value is only consumed when the array is empty. The map callback may
accept one argument (the element value) or up to four arguments (one index per
dimension plus the value). Supports one-, two-, and three-dimensional arrays.

  Topic: Arrays

  See also: std_types::generic_array/std::map,
            std_types::generic_array/std::reduce

  Example:

    $a initialized_array(3 2 0)
    !a(1 1) 1
    !a(1 2) 2
    !a(2 1) 3
    !a(2 2) 4
    !a(3 1) 5
    !a(3 2) 6

    $square: (value)
      -> value*value
