# std_types::generic_array/std::reduce (a method)

  folds an array into a single value by repeatedly applying a binary function

  Parameters:
    self: the array to reduce
    reduce_function?: a two-argument function that combines values
      (defaults to <append>)
    unit?: a fallback value for empty arrays

  Results:
    value: the reduced result

  The reduction order is not guaranteed, so the combine function must be
associative. For one-dimensional arrays the unit is only consumed when the
array is empty — a single-element array returns that element directly.
For two- and three-dimensional arrays the neutral element of the first
entry serves as the starting value. Supports one-, two-, and
three-dimensional arrays.

  Topic: Arrays

  See also: std_types::generic_array/std::map,
            std_types::generic_array/std::map_reduce

  Example:

    $a initialized_array(3 2 0)
    !a(1 1) 1
    !a(1 2) 2
    !a(2 1) 3
    !a(2 2) 4
    !a(3 1) 5
    !a(3 2) 6

    $sum reduce(a plus)
    println! "2D sum: " sum

    $b initialized_array(6 0)
    !b(1) 1
    !b(2) 2
    !b(3) 3
    !b(4) 4
    !b(5) 5
    !b(6) 6

    $product reduce(b times)
    println! "1D product: " product

  Output:

    2D sum: 21
    1D product: 720
