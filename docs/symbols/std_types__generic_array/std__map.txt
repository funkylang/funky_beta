# std_types::generic_array/std::map (a method)

  applies a function to each element of an array, producing a new array

  Parameters:
    self: the array to work on
    map_function: a function receiving either just the element value or
      position indices plus the value and returning the replacement value

  Results:
    the new array of the same shape with mapped elements

  The callback may accept one argument (the element value) or up to four
arguments (one index per dimension followed by the value). The method
supports one-, two-, and three-dimensional arrays.

  Topic: Arrays

  See also: std_types::generic_array/std::map_reduce,
            std_types::generic_array/std::reduce

  Example:

    $print_array: (data)
      $row_count length_of(data 1)
      $column_count length_of(data 2)
      $separator_line append("+" dup("---------+" column_count))
      println! separator_line
      from_to 1 row_count
        : (row_no)
          print! "|"
          from_to 1 column_count
            : (col_no)
              $value data(row_no col_no)
              print! pad_left(value 9) "|"
              next!
          println!
          println! separator_line
          next!
        pass

    # Value-only callback: square each element

    $a array(3 2)
    !a(1 1) 1
    !a(1 2) 2
    !a(2 1) 3
    !a(2 2) 4
    !a(3 1) 5
    !a(3 2) 6

    map $squares
      a
      : (value)
        -> value*value

    print_array! squares

    # Index-aware callback: derive values from row and column

    map $table
      array(3 4)
      : (row col _value)
        -> row*col

    print_array! table
