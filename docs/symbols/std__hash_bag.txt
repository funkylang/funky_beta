# std::hash_bag (a function)

  creates a hash bag from key-value pairs

  Parameters:
    pairs*: one or more KEY = value pairs

  Result:
    a hash bag

  Creates a new hash bag containing the given key-value pairs. Each
  pair's value becomes the count stored for its key. If a key appears
  more than once, the last pair wins and earlier counts are discarded.

  Topic: Bags

  See also: std::empty_hash_bag, std_types::hash_bag,
            std::to_hash_bag, std_types::hash_bag/std::add,
            std_types::hash_bag/std::merge,
            std_types::hash_bag/std::difference

  Example:

    $basket
      hash_bag
        "apple" = 2
        "pear" = 1
        "banana" = 3
    println! "apple: @(basket("apple"))"
    println! "items: @(length_of(basket))"
    debug::dump 99 `basket

  Output:

    apple: 2
    items: 3

  Error output:

    basket:
      hash_bag
        "pear" = 1
        "apple" = 2
        "banana" = 3
