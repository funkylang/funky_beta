# std::dirfd (an I/O-function)

  returns the file descriptor of an open directory

  Parameter:
    directory: the directory

  Result:
    fd: the file descriptor

  **This function must be called with I/O-access rights!**

  Gets the file descriptor for a directory opened with <std::opendir> so it
  can be passed to functions that expect a file descriptor.

  Topic: Input-Output, File System

  See also: std::opendir, std::readdir, std::closedir

  Example:

    opendir! $dir "/tmp"
    dirfd! $fd dir
    dump! `fd

  Output:

    fd: file_descriptor 3
