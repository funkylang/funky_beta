# llama::MAX_TOKENS (a unique item)

  the max tokens option for llama-server completion requests

Use as a key in the options of <llama::complete> to limit the number of tokens
the model may generate. When omitted, the server uses its default maximum.

  Topic: AI

  See also: llama::complete, llama::TEMPERATURE

  Example:

    <require ai/llama_server>

    <using std>
    <using llama>
