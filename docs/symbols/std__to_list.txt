# std::to_list (a polymorphic function)

  creates a list from a collection

  Parameter:
    collection: the collection to convert

  Result:
    list: a list containing all items from the collection

  Converts any collection to a list. The result preserves the order of items
  where the source collection has a defined order.

  Topic: Lists

  See also: std::range, std::append

  Example:

    $s set(3 1 2)
    $items to_list(s)
    debug::dump 99 `items

  Output:

    items:
      list
        3
        2
        1
