# llama_types::metadata (a type derived from std_types::object)

  the metadata returned by llama-server completion requests

  Contains the server-reported information for a completion: the generated
  text, token counts, finish reason, model name, request ID, system
  fingerprint, creation date and time, and optionally logits.

  Returned by <llama::complete> when called with the METADATA option or LOGITS
  set to a non-zero value. Fields not reported by the server remain
  <undefined>.

  Topic: AI

  See also: llama::complete, llama::METADATA

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ What color is the sky on a clear day?"
      METADATA
      MAX_TOKENS = 20
      TEMPERATURE = 0

    println! llama::text_of(meta)

  Output:

    <think>

    </think>

    On a clear day, the sky is typically **blue**.
