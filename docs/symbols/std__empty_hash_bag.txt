# std::empty_hash_bag (an object)

  an empty hash bag

  The empty prototype of the <std_types::hash_bag> type. It is the
  natural starting point when building a bag entry by entry: calling
  the bag with a key and a count adds the key to a cloned bag, and the
  original remains unchanged.

  Topic: Bags

  See also: std_types::hash_bag, std::hash_bag

  Example:

    $basket empty_hash_bag
    !basket("apple") 2
    !basket("pear") 1
    $count length_of(basket)
    println! "items: @(count)"
    debug::dump 99 `basket

  Output:

    items: 2

  Error output:

    basket:
      hash_bag
        "pear" = 1
        "apple" = 2
