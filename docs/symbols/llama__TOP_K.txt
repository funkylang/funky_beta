# llama::TOP_K (a unique item)

  the top-k sampling option for llama-server completion requests

Use as a key in the options of <llama::complete> to limit the token pool to the
K most likely candidates before further sampling. Higher values increase
variety; lower values constrain output. When omitted, the server uses its
default setting.

  Topic: AI

  See also: llama::complete, llama::TOP_P, llama::MIN_P

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "Two plus two equals"
      TOP_K = 10
      TEMPERATURE = 0
      MAX_TOKENS = 3

    println! result

  Output:

    four.
