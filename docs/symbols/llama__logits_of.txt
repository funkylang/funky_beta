# llama::logits_of (a polymorphic function)

  the token log-probability scores reported by the server for a completion

  Parameters:
    meta: a llama_types::metadata object from llama::complete

  Result:
    logits: a list of alternatives per generated token, or undefined if not
            requested

  Holds the log-probability scores for tokens when LOGITS was passed. In
  non-streaming mode the result is a list with one inner list per generated
  token; while streaming, each READ event's metadata carries the single inner
  list for that token. Each inner list holds N key-value pairs of token text
  and log-probability, ordered by probability, where N is the LOGITS value
  (1 when LOGITS is passed bare). Without a LOGITS option the value remains
  <undefined>.

  Topic: AI

  See also: llama_types::metadata, llama::LOGITS

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ What color is the sky?"
      METADATA
      LOGITS = 3
      MAX_TOKENS = 10
      TEMPERATURE = 0.7

    # Show the alternatives for the first generated token
    $token_alts (logits_of(meta))(1)

    println! "Top alternatives for the first token:"
    print! debug::to_string(token_alts 0 3)
