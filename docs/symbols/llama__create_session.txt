# llama::create_session (a polymorphic function)

  creates a new session

  Parameters:
    model: the model to use

  Result:
    model: the model with the new session

  Creates a new session for the model. A session is a context that
  can be used to evaluate prompts. Sessions are used to avoid
  re-evaluating the same prompt multiple times.

  Topic: AI

  See also: llama_types::model/llama::create_session,
            llama::tokenize, llama::evaluate
