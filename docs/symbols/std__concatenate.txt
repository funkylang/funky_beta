# std::concatenate (a function)

  creates a function to concatenate two lists or strings with a separator

  Parameter:
    separator: the separator to insert between the two arguments

  Result:
    function: a binary function that joins two arguments with the separator

  Creates a reusable concatenation function that joins two lists or strings
  with the given separator between them. Call the returned function with two
  arguments to produce the result. Most commonly used with strings.

  Topic: Lists

  See also: std::concatenate_non_empty, std::append

  Example:

    $cat concatenate(" - ")
    $result cat("hello" "world")
    println! '[' result ']'

  Output:

    [hello - world]
