# std::spread (a polymorphic function)

  returns the items of a collection as separate results

  Parameter:
    collection: the collection to spread

  Results:
    items*: the items of the collection, returned as individual results

  Use with care — the number of results equals the collection size, which
  must match the number of destination variables or the calling context.

  Topic: Lists

  See also: std::to_list

  Example:

    $items list(10 20 30)
    spread $a $b $c items
    dump! `a `b `c

  Output:

    a: 10
    b: 20
    c: 30
