# std::errno_of (a polymorphic function)

the errno associated with an error object

  Parameter:
    self: the error object

  Result:
    an error number or undefined if no errno is associated

  This field is used in conjunction with <std::IO_ERROR> and represents
  the contents of the *errno* variable when the error object was created.

  Topic: Errors

  See also: std_types::error, std_types::error_number, std::error_category_of,
            std::error_message_text_of, std::error_details_of,
            std::failed_attribute_of

  Example:

    load! $buf "some-non-existing-file"
    on buf.is_an_error:
      println! "Error: " error_message_text_of(buf)
      $errno errno_of(buf)
      if errno.is_defined
        :
          println! "  errno: " errno.to_integer
        :
          println! "  (no errno)"
