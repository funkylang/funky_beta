# std_types::insert_order_set/std::map_reduce (a method)

  combines a map and a reduce operation into a single operation

  Parameters:
    self: the insert order set to work on
    map_function: the function to apply to each item of the set
    reduce_function?: the function to combine pairs of mapped values
    unit?: the value to return for an empty set

  Result:
    the result of the reduction

  Maps each item in the set, then combines the mapped values into a
  single result. Both steps happen in one pass, so no intermediate
  collection is created to hold the mapped values.

  The *map_function* receives one argument: the item itself. Its
  results are combined pairwise by the *reduce_function*, which
  receives two arguments. The reduce defaults to *append*. When the
  set is empty, the *unit* value is returned.

  Topic: Sets

  See also: std_types::insert_order_set/std::to_list,
            std_types::insert_order_set/std::for_each

  Example:

    $steps insert_order_set("login" "fetch" "store")
    $total map_reduce(steps length_of plus)
    println! total

  Output:

    15
