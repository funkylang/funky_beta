# std_types::insert_order_set/std::first_item_of (an attribute)

  returns the first item inserted into the set

  Parameter:
    self: the insert order set

  Result:
    the first (oldest) item in the set, or undefined if the set
    is empty

  An insert order set keeps its items in the order in which they
  were inserted, so the first item is the oldest one.

  Topic: Sets

  See also: std_types::insert_order_set/std::last_item_of

  Example:

    $steps insert_order_set("login" "fetch" "store")
    println! first_item_of(steps)

  Output:

    login
