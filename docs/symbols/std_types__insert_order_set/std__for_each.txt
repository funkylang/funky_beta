# std_types::insert_order_set/std::for_each (an I/O method)

  invokes a callback for each item in an insert order set

  Parameters:
    self: the insert order set to iterate over
    body: the callback invoked for each item
    finally?: invoked after iteration ends; receives rebound variables
      from the body

  Results:
    the result(s) of the finally callback

  *This function propagates I/O-access rights to its callback body!*

  Iterates over all items in the insert order set. Items are visited
  in insertion order, from oldest to newest. The *body* callback
  receives exactly one argument: the item itself. (A set has no
  values to pass, so the callback never receives a key-value pair.)

  To continue to the next iteration, the body must tail-call *next*.
  Use *next!* (with I/O suffix) when the body contains I/O calls, and
  *next* (without suffix) when it does not. Omitting the *next* call
  exits the loop early, equivalent to calling *break*.

  *break* exits the loop immediately and transfers control to the
  *finally* callback, passing along the current state of any rebound
  variables.

  The optional *finally* callback receives the final state of
  variables rebound inside the body. It is invoked whether iteration
  completes normally, exits via an early *next* omission, or is
  terminated by *break*. When the finally is omitted, *pass* (a no-op
  function) is used as the default.

  Topic: Sets

  See also: std::next, std::break, std::pass

  Example:

    $steps insert_order_set("login" "fetch" "store")

    for_each steps
      : (step)
        println! step
        next!
      pass

  Output:

    login
    fetch
    store

  Example:

    $prices insert_order_set(250 180 320)

    $sum 0
    for_each !sum prices
      : (price)
        plus &sum price
        next
      -> sum

    println! "Total: @(sum) cents"

  Output:

    Total: 750 cents
