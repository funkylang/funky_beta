# std_types::insert_order_set/std::last_item_of (an attribute)

  returns the last item inserted into the set

  Parameter:
    self: the insert order set

  Result:
    the last (newest) item in the set, or undefined if the set
    is empty

  An insert order set keeps its items in the order in which they
  were inserted, so the last item is the newest one.

  Topic: Sets
