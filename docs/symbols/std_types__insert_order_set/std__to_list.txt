# std_types::insert_order_set/std::to_list (a method)

  converts an insert order set into a list

  Parameter:
    self: the insert order set

  Result:
    a list containing the items of the set, in insertion order

  The list preserves the order in which the items were inserted, so
  the first item of the set is the first element of the list.

  Topic: Sets

  See also: std_types::insert_order_set/std::first_item_of,
            std_types::insert_order_set/std::last_item_of

  Example:

    $steps insert_order_set("login" "fetch" "store")
    $list to_list(steps)
    dump! `list

  Output:

    list: list <3>
      "login"
      "fetch"
      "store"
