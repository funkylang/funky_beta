# std_types::insert_order_set/: (a type function)

  retrieve, add, or remove a key while preserving insertion order

  Parameters:
    key: the lookup key
    value?: new state of the key (true to add, false to remove)

  Result:
    true or false on retrieval, or the modified set on add/remove

  Calling a <std_types::insert_order_set> behaves differently
  depending on the number of arguments.

  **One argument:** the key's state is retrieved. The call returns
  <std::true> if the key is present, <std::false> otherwise.

  **Two arguments:** the set is modified. The second argument must be
  a boolean: <std::true> adds the key, <std::false> removes it. A
  cloned set with the change is returned; the original set remains
  unchanged. If the key's state is not actually changed, the original
  set is returned unchanged.

  Topics: Sets, Collections

  See also: std::empty_insert_order_set, std_types::insert_order_table/:

  Example:

    $steps empty_insert_order_set
    !steps("login") true
    !steps("fetch") true
    !steps("store") true
    $present steps("fetch")
    dump! `present
    $grown steps("logout" true)
    $reduced steps("fetch" false)
    dump! `grown `reduced

  Output:

    present: <true>
    grown: insert_order_set <4>
      "login"
      "fetch"
      "store"
      "logout"
    reduced: insert_order_set <2>
      "login"
      "store"
