# std::time_shift_of (a polymorphic function)

  returns the local timezone offset of a date-and-time object in seconds

  Parameter:
    self: a date-and-time object

  Result:
    time_shift: a signed integer

  Returns a signed integer representing the difference in seconds between
  the local timezone and UTC. Positive values indicate timezones east of UTC,
  negative values west. The offset reflects active timezone rules including
  daylight saving time for the given date.

  Topic: Date and Time
