# llama::TOP_P (a unique item)

  the top-p nucleus sampling option for llama-server completion requests

Use as a key in the options of <llama::complete> to set the nucleus sampling
threshold. The model only considers tokens whose cumulative probability exceeds
this value, ignoring the long tail of unlikely tokens. A value near 1.0 allows
all tokens; lower values produce more focused output. When omitted, the server
uses its default top-p setting.

  Topic: AI

  See also: llama::complete, llama::TOP_K, llama::MIN_P

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "The sky is"
      TOP_P = 0.9
      TEMPERATURE = 0
      MAX_TOKENS = 5

    println! result

  Output:

    a beautiful blue.
