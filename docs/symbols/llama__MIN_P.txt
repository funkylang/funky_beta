# llama::MIN_P (a unique item)

  the min-p sampling option for llama-server completion requests

  Use as a key in the options of <llama::complete> to set the minimum
  probability threshold. For each token selection, only tokens whose
  probability is at least MIN_P times the maximum probability are considered;
  all other tokens are discarded before sampling.

  Consider a single selection step where the model assigns these
  probabilities to possible next tokens: "the" = 40 percent (highest),
  "a" = 30, "an" = 25, "this" = 5.

  With MIN_P = 0.1: threshold is 0.1 times 40 percent = 4 percent. All four
  tokens reach it, so none is discarded.

  With MIN_P = 0.6: threshold is 0.6 times 40 percent = 24 percent. Only
  "the", "a", and "an" remain; "this" (5 percent) is discarded.

  The cutoff adapts to the model's confidence: when one token has a clearly
  high probability, few alternatives remain; when the model is uncertain, more
  alternatives survive. When omitted, the server applies no min-p filtering.

  Topic: AI

  See also: llama::complete, llama::TOP_K, llama::TOP_P, llama::TEMPERATURE

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "/no_think/ Continue this sentence: The sky is"
      MIN_P = 0.1
      TEMPERATURE = 0.7
      MAX_TOKENS = 5

    println! result

  Output:

    blue.

    The sky
