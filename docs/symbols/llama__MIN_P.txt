# llama::MIN_P (a unique item)

  the min-p sampling option for llama-server completion requests

Use as a key in the options of <llama::complete> to set the minimum probability
ratio. The model keeps only tokens at least min-p times as likely as the best,
providing an adaptive cutoff per step. When omitted, the server uses its default
min-p setting.

  Topic: AI

  See also: llama::complete, llama::TOP_K, llama::TOP_P

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "Once upon a time"
      MIN_P = 0.05
      TEMPERATURE = 0
      MAX_TOKENS = 5

    println! result

  Output:

    , in a magical land
