# std::finalize (a function)

  cleans up I/O resources and restores terminal state

  This function is similar to a destructor in other languages. It cleans up
  resources and restores the state of I/O manipulations — for example,
  restoring the terminal to its original state after a program has modified
  terminal attributes.

  It is called automatically when the application program exits, but can
  be called explicitly to clean up before delegating control to another task.

  Topic: Input-Output

  See also: std::initialize, std::get_events

  Example:

    std::finalize ()
