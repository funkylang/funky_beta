# llama::SEED (a unique item)

  the random seed option for llama-server completion requests

Use as a key in the options of <llama::complete> to set a deterministic random
seed for generation. Passing the same seed with identical parameters produces
the same output, enabling reproducible results. When omitted, the server uses
a random seed for each request.

  Topic: AI

  See also: llama::complete, llama::TEMPERATURE

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $result "A story about a cat"
      SEED = 42
      MAX_TOKENS = 8
      TEMPERATURE = 0.7

    println! result
