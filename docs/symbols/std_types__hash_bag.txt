# std_types::hash_bag (a type derived from std_types::object)

  a bag for fast random access of items and their counts

  All keys stored in the bag must support the following methods:

  * <hash>

  * <equal>

  A bag is a multi-set: instead of storing a value for each key, it
  stores a count. The count may be negative. Calling the bag with a key
  retrieves the count, or <undefined> if the key is not present.

  Calling the bag with a key and a count returns a cloned bag in which
  that key's count is set to the given count, replacing any previous
  count. If the key is not present yet, it is added. Setting a count to
  zero does not remove the entry; the key remains with a count of zero.
  The original bag remains unchanged. Use <std_types::hash_bag/std::add>
  to increase or decrease a count; it removes the entry when the count
  reaches zero.

  Topics: Bags, Collections

  See also: std::hash_bag, std::empty_hash_bag, std::to_hash_bag,
            std_types::hash_bag/std::merge,
            std_types::hash_bag/std::difference,
            std_types::hash_table, std_types::hash_set

  Example:

    $shelves empty_hash_bag
    !shelves("apple") 3
    !shelves("pear") 5
    !shelves("banana") 2

    println! "apple: @(shelves("apple"))"
    println! "pear: @(shelves("pear"))"

    !shelves("pear") 4
    println! "after rebind, pear: @(shelves("pear"))"

    $deliveries
      hash_bag
        "pear" = 4
        "mango" = 6
    $stock merge(shelves deliveries)
    debug::dump 99 `stock

    $orders
      hash_bag
        "apple" = 3
        "pear" = 4
    $left difference(stock orders)
    debug::dump 99 `left

    !shelves("banana") undefined
    println! "after removal, items: @(length_of(shelves))"

    $shrink add(shelves "apple" = -3)
    println! "after add, items: @(length_of(shrink))"
    debug::dump 99 `shrink

    !shelves("banana") 0
    println! "zero count keeps key, items: @(length_of(shelves))"
    !shelves("banana") undefined
    println! "undefined removes key, items: @(length_of(shelves))"

  Output:

    apple: 3
    pear: 5
    after rebind, pear: 4
    after removal, items: 2
    after add, items: 1
    zero count keeps key, items: 3
    undefined removes key, items: 2
