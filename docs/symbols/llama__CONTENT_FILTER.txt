# llama::CONTENT_FILTER (a unique item)

  the content filter finish reason for llama-server completions

  Delivered as the finish_reason_of attribute of a
  <llama_types::metadata> object
  when generation was stopped by a content filter (e.g., if the model's output
  violated safety guidelines). This signals that the model's response was
  intentionally truncated due to policy enforcement, not natural completion.

  Topic: AI

  See also: llama::finish_reason_of, llama_types::metadata

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Tell me about the solar system."
      METADATA
      TEMPERATURE = 0.5
      MAX_TOKENS = 50

    if
      llama::finish_reason_of(meta) == CONTENT_FILTER
      :
        println! "Content filter triggered"
      :
        println! "No filter issues"

  Output:

    No filter issues
