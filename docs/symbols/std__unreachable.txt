# std::unreachable (a function)

indicates that the program flow reached a point that should never be reached

  Parameter:
    none

  Result:
    an error object

  Calls to this function mark code paths that should logically never be
  executed -- for example, in the final branch of a case expression where
  all other possibilities are covered.

  Returns an error object with the message
  control flow reached "unreachable" point.

  Topic: Errors

  See also: std::Error

  Example:

    $value 1
    case value
      0:
        println! "zero"
      1:
        println! "one"
      :
        unreachable

  Output:

    one
