# std::empty_hash_set (an object)

  returns an empty hash set to use as a starting point

  Parameters:
    none

  Results:
    none

  This is an empty instance of the hash_set type. Use it as the initial value
  when building a new set, then add elements with the call syntax:

    $my_set std::empty_hash_set
    !my_set("item") true

  Topic: Collections

  See also: std_types::hash_set, std::empty_key_order_set

  Example:

    $fruits std::empty_hash_set

    !fruits("banana") true
    !fruits("cherry") true

    print! "Fruit count: " length_of(fruits)
