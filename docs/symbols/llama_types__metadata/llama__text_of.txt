# llama_types::metadata/llama::text_of (an attribute)

  the text content of a metadata object

  Parameters:
    self: the metadata object

  Result:
    text: the generated text, or an empty string if not yet set

  Returns the text carried by this completion. While streaming, each
  READ event's
  metadata contains only the token text for that chunk. With ONE_SHOT or in
  non-streaming mode, this holds the complete generated response. Fields are
  filled by the infrastructure as they become known from the server response.

  Topic: AI

  See also: llama_types::metadata, llama::text_of

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ What color is the sky on a clear day?"
      METADATA
      MAX_TOKENS = 20
      TEMPERATURE = 0

    println! "Text:@nl;" trim(llama::text_of(meta))

  Output:

    <think>

    </think>
