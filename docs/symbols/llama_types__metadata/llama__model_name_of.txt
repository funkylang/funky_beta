# llama_types::metadata/llama::model_name_of (an attribute)

  the model name or path as reported by the server

  Parameters:
    self: the metadata object

  Result:
    name: the model identifier string, or undefined if not yet reported

  The model name or file path that served this completion. Useful when multiple
  models are available on the same llama-server instance and you want to confirm
  which one was actually used. The server includes this in its response header.

  Topic: AI

  See also: llama_types::metadata, llama::model_name_of

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Hello!"
      METADATA
      TEMPERATURE = 0
      MAX_TOKENS = 5

    println! "Model used: " debug::to_string(llama::model_name_of(meta) 0 1)

  Output:

    Model used: "/home/hermes/Downloads/Qwen3.5-2B-Q4_K_M.gguf"
