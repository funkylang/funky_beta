# llama_types::metadata/llama::cached_token_count_of (an attribute)

  the number of tokens served from KV cache

  Parameters:
    self: the metadata object

  Result:
    count: an integer, or undefined if not yet reported

  How many prompt tokens were served from the server's KV
  cache rather than being
  recomputed. A high cached count indicates efficient reuse of context across
  requests. Useful for monitoring cache hit rates and understanding performance
  characteristics on long conversations or repeated prompts.
  This attribute is only
  populated when the server supports and reports cache statistics.

  Topic: AI

  See also: llama_types::metadata, llama::cached_token_count_of,
  llama::CACHE_PROMPT

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Hello there!"
      METADATA
      CACHE_PROMPT
      TEMPERATURE = 0
      MAX_TOKENS = 10

    println! "Cached tokens: "
        debug::to_string(llama::cached_token_count_of(meta) 0 1)

  Output:

    Cached tokens: 4
