# llama_types::metadata/llama::logits_of (an attribute)

  the logits (token probabilities) reported by the server

  Parameters:
    self: the metadata object

  Result:
    logits: a list of key_value_pairs or lists, or undefined if not requested

  Holds the log-probability scores for tokens. The format depends on streaming
  mode and LOGITS option value:

  - Non-streaming with LOGITS = N: a list of N alternatives
    per token
  - Streaming with LOGITS = N: One list of alternatives per token in the stream

  Each entry maps a token text to its log-probability score. Useful for
  understanding model confidence, implementing custom decoding strategies, or
  analyzing model behavior. Only set when LOGITS option was specified with a
  positive value; otherwise remains <undefined>.

  Topic: AI

  See also: llama_types::metadata, llama::LOGITS, llama::logits_of

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ What color is the sky?"
      METADATA
      LOGITS = 5
      MAX_TOKENS = 10
      TEMPERATURE = 0.7

    # Show a sample of the top alternatives for the first generated token
    $token_alts (llama::logits_of(meta))(1)

    println! "Top alternatives for the first token:"
    print! debug::to_string(token_alts 0 3)
