# llama_types::metadata/llama::system_fingerprint_of (an attribute)

  the system fingerprint reported by the server

  Parameters:
    self: the metadata object

  Result:
    fingerprint: a system version hash, or undefined if not yet reported

  A fingerprint that identifies the specific build or configuration of the
  llama-server process. Useful for verifying which server instance handled a
  request, or detecting configuration drift across deployments. The format is
  implementation-defined by the server.

  Topic: AI

  See also: llama_types::metadata, llama::system_fingerprint_of

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Ping"
      METADATA
      MAX_TOKENS = 3
      TEMPERATURE = 0

    println! "Fingerprint: "
        debug::to_string(llama::system_fingerprint_of(meta) 0 1)

  Output:

    Fingerprint: "b10840-73ab7599b"
