# llama_types::metadata/llama::request_id_of (an attribute)

  the unique completion identifier from the server

  Parameters:
    self: the metadata object

  Result:
    id: the request ID string, or undefined if not yet reported

  A unique identifier for this specific completion, generated by the
  llama-server. For example, the format might be chatcmpl-...
  Useful for logging, debugging, or correlating requests across client and
  server. Each call to llama::complete produces a distinct ID.

  Topic: AI

    <require basic/stdlib>

    <using llama>

    complete! $meta "/no_think/ Hello"
