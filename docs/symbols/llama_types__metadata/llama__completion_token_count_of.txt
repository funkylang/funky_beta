# llama_types::metadata/llama::completion_token_count_of (an attribute)

  the number of tokens in the generated output

  Parameters:
    self: the metadata object

  Result:
    count: an integer token count, or undefined if not yet reported

  How many tokens the model generated in response. Useful for monitoring output
  length, detecting early truncation, or estimating cost
  (on paid services). If this
  equals the MAX_TOKENS limit you passed, check finish_reason_of to see if the
  generation was cut off by the length constraint.
