# llama_types::metadata/llama::total_token_count_of (an attribute)

  the total token count (prompt plus completion)

  Parameters:
    self: the metadata object

  Result:
    count: an integer, or undefined if not yet reported

  The sum of prompt tokens and completion tokens. Useful
  for quick cost estimation
  or understanding the overall context size used by
  this completion. For streaming
  completions, this is only available once the response is complete.

  Topic: AI

  See also: llama_types::metadata, llama::total_token_count_of,
  llama::prompt_token_count_of,
            llama::completion_token_count_of

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ What is gravity?"
      METADATA
      MAX_TOKENS = 25
      TEMPERATURE = 0.4

    println! "Total tokens: "
        debug::to_string(llama::total_token_count_of(meta) 0 1)

  Output:

    Total tokens: 33
