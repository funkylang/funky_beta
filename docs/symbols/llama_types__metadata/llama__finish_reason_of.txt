# llama_types::metadata/llama::finish_reason_of (an attribute)

  the finish reason for a completion

  Parameters:
    self: the metadata object

  Result:
    reason: llama::LENGTH, llama::STOP, or llama::CONTENT_FILTER when finished;
            undefined otherwise

  Indicates why generation stopped. The server reports this once when
  generation completes.
  llama::LENGTH means the max token count was reached; llama::STOP means a stop
  sequence was encountered (or the model ended naturally); llama::CONTENT_FILTER
  means the server's content filter intervened. Until the server reports
  a finish reason, this attribute remains <undefined>.

  Topic: AI

  See also: llama_types::metadata, llama::LENGTH, llama::STOP,
  llama::finish_reason_of

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Name three colors."
      METADATA
      MAX_TOKENS = 15
      TEMPERATURE = 0

    println! "Finish reason: "
        debug::to_string(llama::finish_reason_of(meta) 0 1)

  Output:

    Finish reason: llama::LENGTH
