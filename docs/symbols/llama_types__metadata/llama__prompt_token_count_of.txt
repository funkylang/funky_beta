# llama_types::metadata/llama::prompt_token_count_of (an attribute)

  the number of tokens in the input prompt

  Parameters:
    self: the metadata object

  Result:
    count: an integer token count, or undefined if not yet reported

  How many tokens the model processed as input. Useful for
  monitoring token usage,
  estimating cost (on paid services), or debugging when
  completions seem truncated
  (a prompt that exceeds context limits will show it here). The server computes
  this value itself from its own tokenizer.

  Topic: AI

  See also: llama_types::metadata, llama::prompt_token_count_of,
  llama::total_token_count_of

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Explain photosynthesis briefly."
      METADATA
      MAX_TOKENS = 30
      TEMPERATURE = 0.5

    println! "Prompt tokens: "
        debug::to_string(llama::prompt_token_count_of(meta) 0 1)

  Output:

    Prompt tokens: 9
