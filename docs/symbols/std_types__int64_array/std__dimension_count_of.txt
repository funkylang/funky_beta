# std_types::int64_array/std::dimension_count_of (a method)

  returns the number of dimensions of a signed 64-bit array

  Parameter:
    array: a signed 64-bit array

  Result:
    the number of dimensions as an integer

  A one-dimensional array returns 1, a two-dimensional array returns 2, etc.

  Topic: Arrays

  See also: std::dimension_count_of, std_types::int64_array/std::length_of

  Example:

    $records int64_array(3)
    !records(1) 1234567890
    !records(2) -9876543210
    !records(3) 5000000

    println! "dimensions: " dimension_count_of(records)

    $grid int64_array(4 4)
    println! "grid dimensions: " dimension_count_of(grid)

  Output:

    dimensions: 1
    grid dimensions: 2
