# std_types::int64_array/std::length_of (a method)

  returns the length of a dimension in a signed 64-bit array

  Parameters:
    array: a signed 64-bit array
    dimension?: the dimension to query

  Result:
    the length of the specified dimension as an integer

  Without the optional dimension argument, returns the length of the first
dimension. For multi-dimensional arrays, pass the dimension number (1-based)
to get its width. Passing a dimension outside the valid range produces an error.

  Topic: Arrays

  See also: std::length_of, std_types::int64_array/std::dimension_count_of

  Example:

    $records int64_array(4)
    !records(1) 1234567890
    !records(2) -9876543210
    !records(3) 5000000
    !records(4) 9999

    $len length_of(records)
    println! "record count: " len

    $matrix int64_array(2 3)
    println! "rows: " length_of(matrix 1)
    println! "columns: " length_of(matrix 2)

  Output:

    record count: 4
    rows: 2
    columns: 3
