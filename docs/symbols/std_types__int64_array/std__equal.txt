# std_types::int64_array/std::equal (a method)

  compares two signed 64-bit arrays element by element

  Parameters:
    left: a signed 64-bit array
    right: a signed 64-bit array

  Result:
    true if both arrays have the same shape and identical elements,
    false otherwise

  Two arrays are equal when they have matching dimensions and every
corresponding element holds the same value. Arrays with different
shapes always compare as unequal.

  Topic: Arrays

  See also: std::equal, std_types::int64_array/std::less

  Example:

    $grid_a int64_array(2 3)
    !grid_a(1 1) 1000000

    !grid_a(1 3) 2000000

    !grid_a(2 2) 0
    !grid_a(2 3) 999999
