# std_types::int64_array/: (a type function)

  gets or sets an element in an int64 array

Calling a <std_types::int64_array> behaves differently depending on
  the number of arguments.
  Arrays support efficient updates of single elements, unlike lists.

  **One argument:** returns the element at that position (one-based). Values
  are 64-bit signed integers.

  **Two arguments:** returns a cloned array with the value at that position
  set to the new value; the original array remains unchanged. Values outside
  the range wrap using modulo arithmetic.

  Topic: Arrays

  See also: std_types::int64_array, std::empty_int64_array

  Example:

    $large_numbers int64_array(4)
    !large_numbers(1) 922337203685477580
    println! "First number: " large_numbers(1)

  Output:

    First number: 922337203685477580
