# std::stop_injecting_window_change_events (a polymorphic function)

  stop injecting SIGWINCH signals as events into the I/O event loop

  After calling this function, SIGWINCH signals are no longer converted into window
  change events and delivered through the event loop. This is useful when an
  application no longer needs to react to terminal resize events, or when it
  wants to switch to manual polling of terminal dimensions instead.

  Parameters:
    io: the I/O object

  Topic: Input-Output Events

  See also: std::start_injecting_window_change_events, std::stop_catching_signals
