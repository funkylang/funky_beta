# std::exit (a polymorphic function)

  terminates the current program or task

  Parameters:
    exit_code: the exit code to return to the operating system

  Result:
    undefined: this function does not return

  When called with a single exit code (e.g. exit 0) it terminates the
  current program and returns the exit code to the operating system.
  A value of 0 indicates success; non-zero indicates an error.

  When called without arguments it terminates the current task inside
  the input-output loop.

  When called with an error message and exit code it logs the error
  before terminating.

  Topic: Input-Output

  See also: std::exitstatus

  Example:

    exit 0
