# llama::model_name_of (a polymorphic function)

  the model that served a completion, as reported by the server

  Parameters:
    meta: a llama_types::metadata object from llama::complete

  Result:
    name: the model identifier string, or undefined if not yet reported

  The model name or file path that served this completion. Useful when
  multiple models are available on the same llama-server instance and you want
  to confirm which one was actually used. The server includes this in its
  response.

  Topic: AI

  See also: llama_types::metadata

  Example:

    <require basic/stdlib>
    <require ai/llama_server>

    <using std>
    <using llama>

    complete! $meta "/no_think/ Hello!"
      METADATA
      MAX_TOKENS = 5
      TEMPERATURE = 0

    println! "Model used: " debug::to_string(model_name_of(meta) 0 1)

  Output:

    Model used: "/home/hermes/Downloads/Qwen3.5-2B-Q4_K_M.gguf"
