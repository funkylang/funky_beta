# std_types::error/std::error_details_of (a method)

the details associated with an error object

  Parameter:
    self: the error object

  Result:
    additional details or undefined if none are associated

  This field can hold any information useful to the application.
  I/O errors store the file path; "NO SUCH ATTRIBUTE" errors store the
  argument that triggered the error.

  Topic: Errors

  See also: std_types::error, std::error_category_of,
            std::error_message_text_of, std::errno_of, std::failed_attribute_of

  Example:

    load! $buf "some-non-existing-file"
    on buf.is_an_error:
      debug::dump 99 `error_details_of(buf)

  Output:

    error_details_of(buf): "some-non-existing-file"
