# std_types::error/std::errno_of (a method)

the errno associated with an error object

  Parameter:
    self: the error object

  Result:
    an error number or undefined if no errno is associated

  This field is used with I/O errors and represents the value of the
  *errno* variable when the error object was created.

  Topic: Errors

  See also: std_types::error, std::error_category_of,
            std::error_message_text_of, std::error_details_of,
            std::failed_attribute_of

  Example:

    load! $buf "some-non-existing-file"
    on buf.is_an_error:
      debug::dump 99 `errno_of(buf)

  Output:

    errno_of(buf): <error_number 2>
